# 자세 교정 판정 조건 (10/23 범위)

키는 `lib/features/workout/data/kori_feedback_lines.dart`와 같다. 임계값은 전부 임시값이며 한곳(config)에 모으고, 테스트 영상으로 나중에 정한다.

## 공통 전제

- 카메라: 측면 ±15° (squat_knee_valgus만 정면 세트). 폰 세로 고정 전제(화면 아래 = 바닥).
- 판정은 상태 머신의 렙 구간(렙 시작~끝) 안에서만. 셋업·정리 구간, 인식 불확실 프레임은 판정 안 함(침묵).
- 측면에서는 카메라에 가까운 쪽 관절만 사용(confidence 높은 쪽, 흔들림 방지).
- 기준 렙 = 첫 2~3렙의 최고값 또는 중앙값. "1렙 대비"를 쓰지 말 것.
- 각도·편차는 부호 있게 계산(abs 금지). 몸통 각 = 어깨-엉덩이 선의 수직 대비 기울기, 앞뒤는 코 x 위치로 구분.
- 등급: 우선 = 렙 직후 바로 / 개선 = 같은 키 2렙 연속일 때 / 참고 = 세트 후 요약만 / 셋업 = 첫 렙 1회.
- 한 렙에 여러 경고면 등급 가장 높은 것 1개만 말함. 같은 키 쿨다운(초기 3렙).
- 전달(말하기·Flutter `onFeedback`)은 기본 꺼짐: `FormCommonConfig.enabledFeedbackKeys`에 넣은 키만 보낸다. 판정·로그(렙 리포트, 세션 로그, pose-replay)는 항상.

## 푸쉬업 (측면)

| 키 | 등급 | 조건 |
| --- | --- | --- |
| pushup_hip_sag | 우선 | 엉덩이가 어깨-발목 선보다 바닥 쪽으로 기준 이상 (외적 부호, 거리 ÷ 어깨-발목 길이) |
| pushup_hip_pike | 개선 | 같은 지표가 위쪽으로 기준 이상 |
| pushup_shallow | 개선 | 렙 팔꿈치 최소각이 기준 렙보다 기준 이상 큼 |
| pushup_no_lockout | 참고 | 상단 팔꿈치 최대각이 세트 최고값보다 기준 이상 작음 |
| pushup_head_drop | 참고 | 귀가 어깨-엉덩이 연장선보다 바닥 쪽으로, 탑 자세 대비 기준 이상 이동 (코는 쓰지 않음) |
| pushup_head_up | 참고 | 같은 지표가 위쪽으로 기준 이상 |
| pushup_hand_position | 셋업 | 첫 렙 탑에서 손목-어깨 수평 거리 ÷ 팔 길이가 기준 이상 |
| pushup_depth_fade | 참고 | 마지막 3렙 평균 팔꿈치 최소각 − 처음 3렙 평균이 기준 이상 |

- PushUpEvaluator의 시점 가정(top/downward-rear)을 측면으로 바꿀 것.

## 스쿼트 (측면, 맨몸·고블릿)

| 키 | 등급 | 조건 |
| --- | --- | --- |
| squat_hips_first | 우선 | 상승 초반 구간에서 몸통 각이 기준 이상 커지고, 엉덩이 상승 속도 > 어깨 상승 속도 |
| squat_shallow | 개선 | 렙 무릎 최소각(또는 허벅지 기울기)이 기준 렙보다 기준 이상 얕음. 절대 '패럴렐'은 사용자 옵션일 때만 |
| squat_no_lockout | 참고 | 상단 엉덩이·무릎 각이 세트 최고값보다 기준 이상 작음 |
| squat_lean_drift | 참고 | 렙마다 하단 몸통 각이 커지는 추세(마지막 3렙 vs 처음 3렙) |
| squat_depth_fade | 참고 | 렙마다 깊이가 줄어드는 추세(마지막 3렙 vs 처음 3렙) |
| squat_knee_valgus | 우선 | 정면 세트 전용. 렙 하단~상승 구간에서 무릎 간격 < 발목 간격. 다리별 각도(FPPA)는 쓰지 않음 |
| squat_heel_rise | 개선 | 이번 범위에서는 끔(`SquatFormConfig.heelRiseEnabled = false`). Halpe26일 때만. (뒤꿈치 y − 엄지발가락 y) ÷ 정강이 길이가 렙 시작 대비 기준 이상. 발 키포인트 confidence 낮은 프레임 제외 |

- 절대 몸통 각 경고("너무 숙였다")와 "무릎이 발끝 넘음"은 만들지 말 것.

## 바벨로우 (측면)

| 키 | 등급 | 조건 |
| --- | --- | --- |
| row_torso_swing | 우선 | 렙 안 몸통 각 변화량(최대−최소)이 기준 이상 |
| row_standing_up | 개선 | 몸통 각이 기준 렙보다 기준 이상 세워짐 |
| row_short_pull | 개선 | 팔꿈치가 몸통선(어깨-엉덩이) 뒤로 간 거리가 기준 렙보다 기준 이상 작음. 손목 기준(wristToTorsoDistNorm)은 원판 가림 때문에 쓰지 않음 |
| row_head_up | 참고 | 귀가 어깨-엉덩이 연장선 위쪽으로, 렙 시작 대비 기준 이상 이동 |
| row_shrug | 개선(실험) | 렙 시작 대비 귀-어깨 거리 감소율이 기준 이상. 고개 각(코-귀 벡터) 변화 큰 프레임 제외. 정상/으쓱 영상에서 안 갈리면 기능 끔 |

- 절대 몸통 각 경고("더 숙여")는 만들지 말 것(로우 변형마다 정상 각이 다름).
