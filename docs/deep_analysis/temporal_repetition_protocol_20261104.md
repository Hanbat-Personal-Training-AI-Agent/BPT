## Matching and reporting

Within each video independently, solve a global bipartite assignment: maximize matched pair count, then maximize summed exact rational IoU, then minimize summed absolute start plus end error. Equal objectives resolve deterministically by stable vertex/edge order in the documented successive shortest augmenting path solver. Never reuse a prediction or a reference. Predeclared sensitivity at IoU >= 0.25 and >= 0.75 uses the same algorithm; it cannot replace the primary result.
