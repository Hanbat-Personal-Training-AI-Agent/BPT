# GVHMR 심층분석 후보 검증 (1단계)

## 2026-10-29 사용자 지시에 따른 현재 평가 기준

사용자가 처리시간 기준의 근거를 확인한 뒤 **“속도 신경쓰지말고해”**라고 지시했다. 이에 따라 **운동 종료 후 서버 심층분석의 60초 입력/180초 처리 제한은 앞으로의 채택·합격 조건에서 제외한다.** 처리시간은 측정 사실로 보존하며, 이 제한을 맞추기 위한 해상도·프레임 수 축소나 속도만을 위한 추가 실험은 우선하지 않는다. 이 변경은 과거 실험을 소급해 사전 기준 통과로 바꾸는 것이 아니며, 실시간 iPhone 경로의 동작 요건을 바꾸는 것도 아니다.

현재 우선순위는 자세 오류 판정의 정확도, 실제 잘못된 자세의 누락·오경보, 가림 시 판정 보류, 관측 복구, 원본 추론 보존이다. 평균 각도 개선만으로 채택하지 않는다. 로우 몸통 움직임 폭과 푸시업 팔 펴짐의 경계 판정 실패는 아직 해결되지 않았고, 실제 오자세 라벨 검증과 세로 영상 검증도 별도로 남아 있다. 따라서 시간 제한 해제만으로 GVHMR 채택을 결정하지 않는다. 모델 교체·기본값 변경·main/integration 병합은 수행하지 않았다.

10월29일 [프레임별 원인 분석](quality_extrema_results_20261029.md)을 완료했다. 저장 점수4,632개를 정확히 재현했으며 로우의 지속적인 범위 압축과 푸시업의 기준 반복 선택 차이를 확인했다. 단순 시간 이동·단일 극값 제거·up축 변경만으로 해결된다는 근거는 없었다. 이는 기존 사례의 원인 분석 완료이며 오류 수정이나 독립 정확도 검증 완료는 아니다.

10월30일에는 같은 저장 예측에서 표면 기반 H36M 관절을 native SMPL-X 관절 중심으로 바꾸는 [학습 없는 정량 비교](joint_definition_results_20261030.md)를 완료했다. 전체20영상/103반복, 양측 관절, 원 실패 구간과 나머지 구간을 함께 평가했다. 일부 푸시업 각도는 좋아졌지만 로우 범위 압축·반대쪽 팔꿈치·상대 폄 판정이 악화해 이 대체안은 채택하지 않는다. 원본125입력 해시와4,632점 재현을 확인했으며 원 데이터/임계값/제품 경로를 바꾸지 않았다. 같은20개를 재사용한 진단 실험이며 독립 새 정확도 검증은 아니다.

아래 §0은 2026-10-20에 작성된 **과거 사전 기준**이다. 당시 문서의 “사용자 제안 그대로”라는 표현에 대응하는 원래 사용자 발언은 이번 확인에서 찾지 못했으며, 정확히 3분이어야 하는 실험적 근거도 확인하지 못했다. 원기록과 과거 기준에 따른 결과를 보존하되 현재 지시보다 우선하지 않는다.

## 0. 판정 규칙 (결과 보기 전 고정)
용어
- **관절 각도 오차**: 무릎(엉덩이-무릎-발목)·고관절(어깨-엉덩이-무릎)·팔꿈치(어깨-팔꿈치-손목) 굴곡각과 몸통 기울기(골반 중심→어깨 중심이 수직에서 기운 각)를, Fit3D 정답 3D 관절로 계산한 값과 비교한 절대 차이(도). 계산식은 `scripts/eval_3d_angles.py`(뼈 방향 벡터의 arccos)와 같다. 카메라 쪽(카메라 기준 몸에 가까운 쪽) 팔다리, 렙 구간 안의 프레임만.
- **PA-MPJPE**: 크기·회전·위치를 정답에 맞춘 뒤 17관절 위치 오차 평균(mm). 보조 지표.
- **판정 일치율**: 렙마다 앱 규칙(FormWarnings.swift)과 같은 값(렙 무릎 최소각 − 처음 3렙 중앙값 등)을 정답과 각 방법으로 계산해, 임계값을 넘는지(경고 ON/OFF)가 같은 렙 비율. **경계 근처** = 정답 값이 임계값 ±5(도) 안인 렙.
- **렙 정확도** = (정답 렙 − 놓친 렙) ÷ (정답 렙 + 더 센 렙).

비교 대상: A = 지금 실시간 경로(앱 RTMPose-m 2D → MotionAGFormer-XS 3D), B = GVHMR(-s), C = GVHMR(-s, Fit3D 카메라로 계산한 f_mm). 참고로 A2D(앱이 지금 실제로 판정에 쓰는 2D 각도)도 같이 적는다.

통과 기준(사용자 제안 그대로, 아래 해석으로 고정). 전부 만족해야 2단계.
1. 스쿼트·로우·푸시업 각각에서, B 또는 C의 "4개 각도 오차 평균"이 A보다 작다. 그리고 그 변형(B 또는 C)의 판정 일치율이 A보다 낮은 운동이 없다(경계 근처 렙이 있으면 경계 근처, 없으면 전체 렙 기준).
2. 세로 영상(회전 메타데이터 포함)에서 몸이 납작해지거나 기울지 않는다(캡처 + 뼈 길이 변동·깊이 폭·직립 몸통 기울기).
3. L4에서 60초 영상 처리 ≤ 3분(콜드 스타트 제외).
4. L4 VRAM 최대 ≤ 22 GB.
5. 렙 정확도가 지금 기록보다 낮지 않다. Exercise3D 영상은 Home에 없으므로 같은 Fit3D 영상에서 A(같은 단순 카운터)와 비교한다.
- B와 C가 둘 다 통과하면 세 운동 평균 각도 오차가 작은 쪽을 2단계에 쓴다.
- 데드리프트는 Fit3D에 앱 2D 재생(pose-replay) 결과가 없어 A가 없음 → 기준 판정에서 빼고 B·C만 기록.
