# 허리 굽음과 몸통 전경을 구분하기 위한 관측 가능성 검사

## A. 질문과 정의

`180 − angle(pelvis0, spine7, thorax8)`를 3점 굴곡 proxy로 계산하고, 골반 중점→어깨 중점 벡터의 수직 대비 각도를 별도로 계산했다. 이 proxy는 부호 없는 세 가상 관절의 각도다. 실제 요추 곡률, 허리 둥글게 굽힘 라벨, 부상 위험 또는 정상 범위를 의미하지 않는다. 전후 굴곡·측굴·신전을 구분하지 못한다.

## B. 데이터와 경계

원래 사전 고정 Fit3D 20영상의 반복 안 프레임만 사용한다. 기존 GT·XS·GVHMR B/C·floor 배열을 Home CPU에서 읽었으며 새 추론·학습은 없다. GT는 평가에만 사용한다. 원영상·배열·개인별 프로필은 Home에 남기고 운동별 집계만 반출한다. 기본 평가의 재사용11/신규9와 과거 입력 해시 미보존 한계는 [정량 평가](gvhmr_fit3d_20261026.md)를 따른다.

XS는 과거 COCO17 RTMPose-m→H36M XS 캐시 15개다. 현재 C3의 동일 Fit3D 프레임 배열은 찾지 못했다. 발견된 C3 Fit3D 파일은 집계만 있고, 다른 데이터셋의 C3 배열은 표본에 섞지 않았다. 따라서 C3의 허리 굽음 정확도는 미평가다.

## C. 계산과 검증

proxy는 회전 불변이다. 전체 몸통 기울기는 GT/floor의 world up, GVHMR world +Y, XS camera image up(−Y)을 사용하므로 XS 몸통 비교에는 좌표 정의 차이가 포함된다. MAE는 운동 내 프레임 가중이고, 상관은 영상별 Pearson 상관의 중앙값이다. 본 평가의 영상별 macro 평균과 분모가 다르다. GT 표준편차 0.001° 미만이면 상관을 산출하지 않는 수치적 방어만 두었다. 임상 기준이 아니다.

합성 단위 검증 2개 통과: 몸통 전체를 60° 기울이면 proxy 0°/전체 기울기 60°, 윗부분만 30° 꺾으면 proxy 30°/전체 기울기 15°. 퇴화한 영벡터는 NaN 처리하고 상수 GT에는 상관을 만들지 않는다.

## D. 전체 결과

[전체 집계 JSON](spine_proxy_20261026.json). GT/GVHMR B/C/floor 각20개, XS15개 완료. 모든 운동에서 수치적으로 상수인 GT 영상은 0/5였다.

| 운동 | GT proxy 범위 | GT 전체 표준편차 | 영상 내 표준편차 중앙값 |
|---|---:|---:|---:|
| 스쿼트 | 0.02–48.85° | 13.62° | 8.97° |
| 로우 | 2.23–59.21° | 17.10° | 2.12° |
| 푸시업 | 0.16–32.20° | 7.66° | 1.58° |
| 데드리프트 | 0.96–50.93° | 12.73° | 5.68° |

GT proxy는 이 표본에서 수치적 상수가 아니다. 다만 0.001°는 계산용 기준이므로 이 검사만으로 실제 동작에서 거의 고정인지 여부를 판정하지 않는다. 특히 로우/푸시업은 전체 분산보다 영상 내부 변화가 작으므로 피험자 간 차이를 시간 추적 성능으로 오인하면 안 된다.

| 운동 | XS MAE / 상관 | B MAE / 상관 | C MAE / 상관 | floor MAE / 상관 |
|---|---:|---:|---:|---:|
| 스쿼트 | 20.22° / -0.092 | 18.62° / 0.772 | 18.61° / 0.789 | 19.24° / 0.604 |
| 로우 | 17.82° / -0.250 | 20.36° / -0.021 | 20.36° / -0.012 | 20.74° / 0.127 |
| 푸시업 | 11.39° / 0.027 | 6.69° / 0.250 | 6.71° / 0.278 | 6.04° / -0.052 |
| 데드리프트 | 미평가 | 13.50° / 0.331 | 13.52° / 0.341 | 12.41° / 0.439 |

별도 전체 몸통 기울기 MAE(B)는 스쿼트8.54°/로우7.57°/푸시업5.85°/데드리프트7.36°다. proxy와 별개의 기하량이며 어느 쪽도 실제 요추 굴곡 분류 정확도가 아니다. 스쿼트 B/C proxy 상관이 높더라도 약18.6° MAE와 정의 차이가 남는다. 로우 B/C의 중앙 상관은 0 근처이며, 이 수치로 세밀한 허리 굽음 코칭을 검증했다고 말할 수 없다.

## E. 해석

GT proxy의 변화가 있다고 해서 그것이 임상적 요추 굴곡의 정답이 되는 것은 아니다. floor는 GT SMPL-X를 neutral 체형 및 H36M regressor로 옮긴 oracle 정의 차이 진단이다. 이 경우에도 proxy 차이가 남으면 관절 정의·체형 변환이 큰 영향을 준다는 뜻이며, 추정 모델의 보장 가능한 오차 하한으로 사용할 수 없다.

COCO17은 내부 spine7/thorax8을 독립 관측하지 않는다. 어깨·골반의 높은 2D 검출 지지도만으로 내부 척추 곡률을 확인할 수 없다. 서버의 torso support gate는 몸통 끝점의 지지 조건이며 실제 요추 곡률의 관측 가능성을 증명하지 않는다.

## F. 한계

표본은 사선 고정 카메라·피험자 5명·운동 4개다. 허리 굽음 오류 라벨이나 전문가 판정이 없고, proxy와 몸통 기울기의 분리는 기하적 구별일 뿐 행동 분류의 타당성 검증이 아니다. C는 GT 초점거리를 입력으로 사용하는 oracle 실험이다. 체형 개인화 효과 검증이 아니다.

## G. 권고

제품에서 상체 전경을 허리 둥글게 굽힘이라고 표시하지 않는다. 이 proxy는 관절 정의를 명시한 진단 정보로만 유지하고, 실제 허리 굽음 코칭은 라벨과 관측 가능한 입력을 갖춘 별도 검증 전에는 유효한 판정으로 채택하지 않는다. 진단 기본 OFF 유지 권고는 실험 근거의 한계에 따른 것이며 정상 판정으로 대체하지 않는다.
