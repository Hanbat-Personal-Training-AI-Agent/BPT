# 진행 기록 2026-10-11

## 트랙 C 후속 — iPhone 2D 모델 속도 (ai/pose2d-device)
- `tools/pose_model_bench` 확장: 실제 720×1280 프레임 입력, Apple Vision 참고 측정(`testVision`), 연속 실행(`testSustained`: 10초마다 FPS·발열 상태), 실행 사이 휴식(`BENCH_COOLDOWN`), 호스트 앱 화면 꺼짐 방지.
- iPhone 17에서 4개 모델 × ALL/CPU+NE/CPU+GPU 지연, Vision, 연속 150초(s COCO17·s Halpe26·m COCO17) 측정. m Halpe26 연속 실행은 휴식 중 기기가 잠겨 못 잼.
- 결과·판단: D-C-05, `docs/results/summary.md` §3. 기본 모델 변경 없음.

## 실기기 전체 파이프라인 (ai/device-pipeline)
- `tools/pose_model_bench` 호스트 앱에 영상 입력 라이브 모드(`Host/PipelineBench.swift`, `run_pipeline.sh`): AVAssetReader 디코딩 → 라이브 카메라와 같은 프레임 코드. 30 fps 페이스 / 무제한, 녹화·3D·m 변형, 10초마다 FPS·놓친 프레임·발열·배터리, 기기 키포인트 CSV 내보내기(`BENCH_DUMP=1`).
- 프레임당 포즈 단계를 `RTMPoseCropTracker.estimate`로 뽑아 CameraPosePreview·pose-replay·벤치 공통(동작 그대로, 새 테스트 1개).
- 실수 정정: 처음 푸시업 영상(가로 1920×1080)을 세로 720×1280으로 늘려 렙이 2–4로 나옴 → 가로 1280×720으로 다시 만들어 전부 재측정(먼저 잰 a 결과는 버림).
- 결과·판단: D-E-08(녹화 OFF 유지), D-C-06, `docs/results/summary.md` §5.1.
