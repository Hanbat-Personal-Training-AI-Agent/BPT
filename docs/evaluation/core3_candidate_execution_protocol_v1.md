This apparatus/variant check is not a form label or angle measurement. Bodyweight squat remains a separately registered configurable variant but is not the variant declared for this actual replay. Every window records actual membership and brackets. Reset or withhold on source/epoch, coordinate or selected-side changes, source gaps/nonmonotonicity, missing phase start, flush tails or relevant support loss; do not silently rebaseline midphase. A partial rolling window cannot prove a non-exceedance. A completed bottom target needs an observed entering and exiting boundary plus all required samples. Preserve denominators for every original genuine and flush opportunity.

Native synthetic positive/negative/occlusion/disjoint/consecutive-source counterexamples and Python/native request parity precede outcome replay.

The live opt-in branch uses caller configuration already loaded before its source frames.
