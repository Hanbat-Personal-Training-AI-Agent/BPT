# 핵심 3운동의 자세 기준과 관측 계약 v1

작성·출처 재확인: 2026-11-02. 범위는 푸시업·스쿼트·바벨 로우다. 현재 앱의 다른 운동을 제거하거나 랫풀다운을 추가하는 문서가 아니다. 이 문서는 구현과 독립 평가를 위한 기준이며, 검증된 정확도·임상 위험 경계·기본 설정 채택을 선언하지 않는다. MotionAGFormer-XS와 원본 관절을 유지한다.

## 정자세 목표, 변화 감지, 측정 가능성을 구분한다

`technique_target`은 선택한 운동 변형에서 수행하려는 동작이다. `metric`은 현재 관측으로 계산한 수치이고, `criterion`은 그 수치를 특정 목표와 비교하는 결정이다. 세 가지가 연결돼야 교정 근거가 된다. 관절각을 계산할 수 있다는 사실만으로 자동 판정 기준이 검증되지는 않는다.

기준 출처는 다음과 같이 보존한다.

| 종류 | 의미 | 허용되는 해석 |
| --- | --- | --- |
| `technical_guidance` | 협회 등의 동작 지침 | 선택한 변형의 기술 목표. 자동 감지 숫자는 별도 검증 |
| `research_condition` | 연구에서 측정하거나 비교한 조건 | 대상·운동 단계·좌표 정의가 맞는 범위에서 참고. 부상/정상 경계로 자동 전환 금지 |
| `engineering_candidate` | 명시적으로 고정한 실험 수치 | 검토 후보의 초과/미초과. 검증된 정자세 판정 아님 |
| `explicit_target` | 버전·변형·출처와 함께 확인한 목표 | 해당 목표와의 일치 여부. 목표 확인과 센서 정확도 검증은 별개 |
| `observed_first3` | 처음 세 반복에서 관측한 값 | 이전 반복 대비 변화만 설명. 정상 자세 목표로 승격 금지 |
| `unresolved` | 적절한 기준/관측이 없음 | 이유를 포함한 보류 |

현재의 `approved: Bool`만으로는 목표의 권위를 입증하지 못한다. 향후 연결에는 운동/변형, 기준 버전, metric 정의/단위/좌표, 수치 또는 범위, 설정 출처, 확인자 종류, 확인 시각, 원본 근거, 유효 조건과 만료 사유가 필요하다. 첫 반복이나 캘리브레이션 완료가 이 필드를 자동 승인하지 않는다. SMPL 치수는 관절 기하의 개인화 근거이며, 정자세나 정확한 실제 뼈 길이라는 증거는 아니다.

## 복합 평가의 결정 규칙

관절별 confidence, raw/corrected 차이, invalid mask, 추적, 시각·좌우·운동 단계·카메라 조건을 먼저 보존한다. 높은 RTMPose score는 정확한 3D나 실제 가시성의 확률이 아니다. 가려진 관절의 예측값에는 예측 출처·경과 시간·불확실성을 붙이며 직접 관측으로 바꾸지 않는다.

관절 자체의 해부학적 좌우와 현재 판정기가 선택한 측은 서로 다른 정보다. 오른팔 각도는 왼쪽을 선택한 프레임에서도 오른팔 측정값으로 남겨야 한다. 현재 `sideView`는 어깨 비율 기반의 측면 여부 추정이다. `false`는 '측면 조건 미충족'이며 정면이나 사선을 확정하지 않는다. 이 플래그만으로 정면 전용 기준을 적용하지 않는다.

각 조건은 `positive_evidence`, `negative_evidence`, `unknown`, `not_applicable`로 구분한다. 외부 보고의 `warning/no_warning/withheld/missing`과 실제 음성 전달 여부는 별도다.

- AND 조건은 **같은 시각/위상 범위**의 모든 필수 항목이 지지해야 충족된다. 한 항목이 확인됐어도 나머지가 unknown이면 복합 판정은 보류하되 확인된 항목은 남긴다.
- OR 조건은 신뢰할 수 있는 한 항목이 지지하면 그 항목의 근거를 보존한다. 다른 항목의 결측을 이유로 확인된 편차까지 없애지 않는다. 모두 미초과라도 필요한 항목이 unknown이면 전체를 음성 판정하지 않는다.
- 순간 최대 편차의 유효 초과와, 반복 최소각/전체 ROM의 판정은 다르다. 후자는 필요한 단계 전체를 관측하지 않으면 놓친 극값 때문에 판정 방향 자체가 바뀔 수 있다.
- 지속시간은 원본 sample PTS로 계산한다. 관측 사이의 누락 시간이나 위상/좌우 변경을 이어 붙여 지속 조건을 채우지 않는다.
- 각각의 정상 범위 관측을 합쳐 운동 전체를 정상이라고 인증하지 않는다. 불확실한 부위는 보류하면서 다른 부위의 확인된 교정 근거를 유지한다.
- 반복 중 미래 프레임과 이후 반복을 현재 기준에 포함하지 않는다. 세트 후 분석의 미래 접근 조건은 실시간 조건과 구분한다.

이는 제품의 논리 계약이다. 실제 오자세 판별력은 [독립 평가 프로토콜](independent_form_protocol_v1.md)의 별도 라벨과 고정 분모로 검증한다.

Suprak 등의 실험은 건강한 참가자 16명의 어깨 위치별 견갑 운동을 해부학적 좌표계로 측정했다. 논문의 60° 권고를 현재 투영 상완각의 즉시 경고 한계로 복사하지 않는다. 측정 정의가 다르고, 연구는 앱의 판정 정확도나 보편적인 부상 경계를 검증하지 않았다. [원 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC3867095/), [PubMed 초록](https://pubmed.ncbi.nlm.nih.gov/23952043/)

## 스쿼트

백스쿼트의 바 위치·스탠스를 바꾼 실험은 관절 기여와 운동학이 조건에 따라 달라짐을 보고했다. 따라서 고정된 몸통 기울기 하나를 모든 스쿼트 변형의 정자세로 쓰지 않는 것이 본 계약의 제품 판단이다. 이 연구에서 앱의 오자세 임계값을 얻었다고 주장하지 않는다. [Larsen 등, 2021](https://pubmed.ncbi.nlm.nih.gov/34541522/)

## 구현 연결과 합격 증거

현재 native 수식·임계·전달 범위는 [코칭 소스 감사](../results/coaching_rule_crosswalk_20261103.md)를 따른다. 기존 기본값은 그대로 둔다. 새 비교는 관측 전용이며 다음을 개별 보존해야 한다.

1. 원본 영상/입력 hash, source commit, rule/metric version, 실제 coordinate/units/joint definition.
2. 원본 시각, 반복 포함 경계, actual sample membership, 선택 측 이력과 phase/view 근거.
3. raw·corrected 및 보정 크기/invalid·지원 점수·관측/예측 출처, 누락 사유와 분모.
4. explicit target과 observed first3의 구분, 기준에 쓰인 실제 이전 반복 식별자, 이후 반복 미사용.
5. 개별 조건과 복합 조건, `judged`·`delivered`·`withheld`·`missing`의 구분. 특정 조건 미초과를 전체 정자세로 바꾸지 않음.

수식/계약 회귀는 실제 정확도 시험과 별개다. 합성 반례에는 첫 세 번부터 같은 오류가 있는 경우, 한쪽 가림 중 반대쪽의 확실한 편차, AND의 한 항목만 확인된 경우, 좌우 전환, 미래 기준 누수, 끝 프레임 차이, 보정으로 각도가 달라지는 경우를 포함한다. 실제 기록 재생에서는 available/withheld와 그 이유를 모든 원래 기회 위에서 보고한다. 독립 정상/오류 판정이 없는 자료에서 precision/recall 또는 '정자세 교정 완료' 수치를 만들지 않는다.

본 문서의 기준 범위를 구현·테스트하고, 관측 부족은 구체적으로 보고한다. 추가 모델 학습·실험 기본 활성화·모델 교체·integration 병합·배포는 이 문서로 승인되지 않는다.
