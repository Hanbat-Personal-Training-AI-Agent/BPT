## 요약 (쉬운 말)
- **발 방향 기준으로 바꿔도 지금 형태로는 쓸 수 없다.** 정상 스쿼트에서도 무릎은 늘 발 방향보다 안쪽에 있다. 그래서 미리 정한 고정 기준(V2 0.10, V1 0)으로는 정상 렙의 94–100%가 울린다. 모캡 참값(Fit3D 발끝)도 정상 렙 중앙값이 0.12–0.17 안쪽이라, 이것은 모델 오차가 아니라 실제 자세다.
- 조정 데이터로 기준을 다시 정하면 오경보는 0–1%가 되지만 기준이 정강이의 0.67–0.89배로 아주 느슨해져 사실상 꺼진다. AI 라벨 무릎 모임 bad 클립 3개 중 0개를 잡는다.
- **시점 의존은 줄지 않았다.** 정상 렙 중앙값이 정면 0.21 → 사선 0.40(V2)으로 사선에서 더 크다. 간격비의 사선 문제(정면 1.04 → 사선 0.82)와 방향만 같다.
- V2(XS 3D + 2D 발)는 모캡 V2*와 잘 맞지 않는다: |오차| 중앙값 0.056, p90 0.33, 상관 r = 0.20.
- 패리티: 같은 렙 1411개의 3D 간격비가 rules-calib 세트와 완전히 같다(차 0, 게이트 1411/1411). 그래서 같은 데이터·경로라고 확인했다. 공개 정면+사선 렙의 현재 기준 오경보 (61+98)/254 = 63%도 rules_calib.md와 같다.

## 정의 (사전 등록 그대로)
- **V2(주)**: 발목을 지나고 위 방향과 발 방향 f를 담는 수직 평면에서 무릎이 안쪽으로 벗어난 정도 / 정강이 길이. f는 2D 뒤꿈치→엄지 벡터의 화면 x 성분과 발 길이 사전값(0.6 × 정강이)으로 구한 수평 방향이다.
- **V1(보조, 2D)**: 무릎이 엄지발가락 세로선보다 안쪽인 정도 / 2D 정강이.
- **V2***: Fit3D 모캡 발끝(joints3d_25의 18/20)으로 잰 참값.
- 렙 창: 엉덩이가 가장 낮은 프레임부터 렙 끝까지. 두 다리 중 나쁜 쪽.

## 판단 (사전 등록 기준)
- 기준: "V1 또는 V2가 정면·사선 모두에서 고정 기준 오경보 ≤ 5%이고 간격비보다 낮다" → **충족하지 않음**(고정 기준 94–100%).
- 바뀐 판단: "사선에서 간격비가 1.0 아래로 떨어지는 것은 기준이 발 방향을 무시해서"라는 가설 → **이 데이터로는 지지되지 않는다.** 발 방향을 넣은 지표도 사선에서 정상 값이 더 커진다. 사선 문제는 정의보다 시점(2D 투영과 XS 깊이 오차) 쪽으로 보인다(가설).
- 가설: 정상 스쿼트의 무릎이 발 평면보다 안쪽인 것은 렙 창(가장 낮은 지점 이후)에서 무릎이 몸 앞쪽으로 나가고, 발은 바깥으로 돌아가 있기 때문으로 본다. 모캡 V2*의 p5 0.08로 보아 "0을 넘으면 모임"이라는 단순 기준은 맞지 않는다. 쓰려면 같은 사람의 첫 렙 기준선 대비 변화로 정의해야 할 수도 있다(확인 안 함).
