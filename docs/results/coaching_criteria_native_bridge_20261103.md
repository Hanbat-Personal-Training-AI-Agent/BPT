# Default-off native criteria diagnostics bridge

`CoachingCriteriaBridge` now maps the existing nine ExperimentalCoaching metrics to the independent native criteria evaluator. Camera computes the existing diagnostics once under `BPT_EXPERIMENTAL_COACHING=1`, resets diagnostic history on source/epoch/index transitions, reuses the legacy log, and attaches a bounded optional `coaching_criteria` payload to the existing `terminal_frame`. Flag off adds no criteria evaluation, profile/file loading or inference. The existing normal judge, form warnings, voice and pose calculations are unchanged. No profile or target is created; `variant` remains unconfirmed.

The versioned payload keeps source epoch/frame/index/PTS/rational/source kind, phase/selected side/view Bool/flush, original metric raw/value/availability/reasons and scoped decision reasons. Two camera proxies not supplied by the native diagnostic source are explicitly listed. A flush observation cannot become evidence. Encoding/evaluation failure produces a bound `withheld_error` marker with a fixed reason instead of silently dropping an enabled observation. Payload limit is32768bytes; metric and reason counts/lengths are bounded.

The strict terminal reader accepts legacy rows with no optional payload. When present, it validates the schema, profile-free scope, bounded shape, every source identity/clock field, matching phase/selected side/view/source kind/flush and the current terminal_start exercise. Positive/negative posture claims, stale epochs, mismatched source PTS/rational/index and unknown failure alternatives are rejected. Duplicate original flush reasons remain evidence.

`side_view=false` means not side, and maps to unknown rather than frontal. Metric anatomical left/right is derived from metric identity; selected side remains a separate history field; centreline quantities use bilateral. Original source Bools and values are preserved.
