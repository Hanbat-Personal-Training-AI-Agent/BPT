# Bone target continuity experiment: predeclared protocol — 2026-11-02

Declared before computing candidate capture results, on parent02937c2. One engineering candidate, no sweep or tuning: positive target dictionaries normalized by their sum, linear shape EMA with source-time half-life0.2s (`alpha=1-exp(-log(2)*dt/0.2)`). Uniform target scaling has no geometric meaning to the bone solver. Prior→session source-label changes do not reset. No joint positions, velocities, direction, reference angles, GT or anatomical success criterion enter the filter.

Missing/nonfinite timestamps, non-increasing source time, invalid/nonpositive/nonfinite target shape, empty profile epoch or lost tracking: explicit unsupported result and clear state. No assumed30fps fallback. Explicit reset clears state; a changed profile epoch, changed target keys or gap>1.0s starts directly at the new shape and reports why. These bounds are engineering candidate choices, not validated exercise timing or accuracy limits. A profile epoch is caller-owned; reset/change it when a person/session/profile changes. New profiles never blend with previous epoch state. Sparse source time within the allowed gap uses actual dt.

Offline-only module under scripts/wrist_observation, no app target/callsite/default change. Replay applies original native raw3D arrays in original emitted order using original per-frame target dictionaries (population prior then running median). Filter only those target shapes, then run the unchanged production full constraint stack with filtered targets; all current raw arrays remain unchanged. Explicit flush rows preserve history but are excluded from reported temporal/angle distributions. Track/reset handling is tested synthetically; actual captures have no tracking-loss reset. The baseline must first reproduce all stored constrained coordinates and invalid masks before reporting counterfactuals.

Report all three development sets, both sides, every eligible contiguous source interval; original and candidate speed distributions and top changes with same-frame raw/full/candidate comparisons. Compare every configured interior angle (bilateral knees/elbows/hips/shoulders and spine), plus geometric native hip, knee, elbow and torso diagnostics where definitions are available. Keep original maxima and candidate maxima separate; paired summaries cannot silently change sample sets. No new score/angle/motion cutoff and no selection of a favorable side. Verify isolated raw direction changes remain current-frame direction changes, independent of the filtered target shape.

This targets the discrete target-shape transition only. It does not claim to solve collapsed raw direction times enforced length, establish accuracy, suppress actual unwanted movement, improve coaching or reduce false negatives. Reduced numerical jitter alone cannot justify adoption. No inference, GPU, phone commands, upload, deployment or automatic runtime activation.
