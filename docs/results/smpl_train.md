# smpl-train: 체형(SMPL β → 뼈 길이)을 알면 MotionAGFormer-XS 3D 관절 각도가 좋아지나 (D-D-08)

날짜: 2026-10-17 · 트랙 ai/smpl-train · 스크립트 `scripts/train_lifter_body_shape.py` · Home GTX 1060에서 학습·평가

## 1. 방법
- **입력 2D**: 앱과 같은 RTMPose-m COCO17(crop)을 Mac pose-replay로 실제 Fit3D 영상에 돌린 키포인트(정답 2D 아님, 실제 모델 잡음 포함).
- **체형**: Fit3D에는 SMPL이 없어(SMPL-X·GHUM만 제공) 사람마다 모캡 구간 길이 중앙값에 맞는 SMPL β(10개)를 맞추고,
  캘리브레이션 서버와 똑같이 β → 기본 자세 메시 → H36M 관절 → `body.bone_lengths_cm`로 "캘리브레이션 뼈 길이"를 만듦.
  맞춤 잔차(구간 길이 평균 |%|): 조정 3명 1.5–2.2%, 검증 5명 3.0–5.2%.
- **캘리브레이션 오차 흉내**: 구간마다 독립 로그정규 σ 3.75%(평균 |오차| ≈ 3%, F4 검증 2.83%와 비슷). 학습은 창마다 새로 뽑고,
  평가는 고정 3번 뽑아 합침. `_oracle` = 오차 없는 길이.
- **변형** (모두 같은 데이터·10에폭·배치 16·AdamW 1e-4 cosine·좌우 뒤집기, D-D-06/07 방식):
  - a 기준(위치 손실만), b a + 뼈 길이 조건(FiLM, 길이 비율만 사용), c a + 모듈별 손실(관절 각도·뼈 비율·가속도),
    d b + c, e(평가만) 예측 뼈를 캘리브레이션 비율로 다시 맞춤(학습 없음, `e_a` = a에 적용).
- **분할**: 학습 s03–s05, 검증 s07–s11(선택에 안 씀). Exercise3D는 라벨이 Sapiens 유래라 상대 비교만.

쉬운 말 풀이:
- **MPJPE**: 관절 위치 평균 오차(mm). **PA-MPJPE**: 크기·회전을 맞춘 뒤 오차(mm, 자세 모양만). **accel**: 떨림(프레임당 가속도 오차, mm).
- **각도 칸**: 렙마다 가장 깊은/높은 순간의 관절 각도 오차 중앙값(°), 괄호 = 상위 10%(p90). **굵게** = 중앙값 ≤ 5° 그리고 p90 ≤ 10°
  (경고 문턱 15°대와 가를 수 있는 수준, D-D-07과 같은 기준). torso_g = 중력 기준 몸통 기울기.

## 3. 해석
- **전체 위치 오차는 거의 같다**: 가장 좋은 d도 a보다 1.25 mm(2.4%) 낮을 뿐(D-D-07 미세조정 XS 52 / 38 mm와 같은 수준). 5명 모두 조금씩 좋아짐.
- **b·d에서 잡음 길이와 정확한 길이(oracle)가 같음** → 모델이 뼈 길이 입력을 거의 안 씀(또는 3.75% 잡음에 둔감). 캘리브레이션 정확도가 병목이 아님.
- **사후 뼈 맞춤(e)**: 정확한 길이면 위치 −3.2 mm로 가장 큰 개선이지만, 3% 잡음 길이에서는 −1.4 mm이고 좋아진 영상이 절반 이하.
  엉덩이 각은 좋아짐(Exercise3D 측면 푸시업 엉덩이 6.9 → 3.8°, 사선 스쿼트 엉덩이 6.3 → 3.3°), 몸통(torso_g)은 0.2–1.3° 나빠짐.
- **관절 각도 기준(굵게) 통과 칸 수(Fit3D 검증)**: a 2, b 2, c 2, d 3. b·c·d가 새로 통과한 칸은 로우 몸통(중력) 4.3–4.8°(a 5.0, p90 10으로 경계), 대신 b·c는 푸시업 엉덩이가 경계 밖으로(3.9 → 3.9–4.1, p90 10 반올림 경계).
  무릎은 b·c·d 모두 a보다 0.4–0.9° 나쁨(5.0 → 5.4–5.9). 팔꿈치는 c·d 중앙값이 좋아지고(7.8 → 7.2–7.4) p90은 나빠짐(19 → 21–22).
- **Exercise3D 측면(≤40°)**: 몸통 17–19°는 어떤 변형도 해결 못 함(Fit3D에 측면 카메라 없음, D-D-07과 같음). c는 스쿼트 무릎이 나빠짐(6.7 → 9.3°).
- **결론**: 체형 조건·모듈 손실의 이득은 1 mm·1° 안팎으로 작고 관절마다 엇갈림. 앱 동작을 바꿀 근거로는 부족.

## 4. 한계
- 검증 5명, 사선 카메라만(56–75°). Exercise3D 각도는 Sapiens 유래 라벨이라 상대 비교만, 사선은 7영상뿐.
- β는 모캡 길이에 맞춘 값이라 실제 사진 캘리브레이션(옷·자세 오차)보다 깨끗함. 잡음 σ 3.75%는 F4 수치로 정한 추정.
- d를 고를 때 검증 결과를 봄(조정 세트 평가 없음) → "d가 가장 좋다"는 추정, 차이가 작아 다른 사람에서 뒤집힐 수 있음.
- Core ML 변환·기기 속도·렙 정확도(Mac)는 안 함: pending (Mac).
