- **Core ML 변환 경로**: XS — 원래 XS를 같은 도구(`scripts/finetune3/coreml_xs_export.py` = lift-compare `coreml_ft_export.py`)로 변환하면 PyTorch 대비 선택 행 관절 거리/퍼짐 ALL 0.20%, CPU_ONLY 0.25%(lift-compare 기록과 같음).
