- Exercise3D는 의사 정답이며 C1은 Exercise3D로 학습하지 않았다(독립). 푸시업은 Exercise3D 검증 피험자가 없다(P1뿐).

#### C1 몸통 원인 분리 진단 (결과 후 조사, 2026-10-20 재개)
- 확인/배제/미확인 결과와 재현 manifest는 [c1_torso_diagnostic.md](c1_torso_diagnostic.md)에 정리했다. 측면에서 C1의 위축 독립 벡터 오차 10.55°(원래 4.17°), 출력 XY/입력 2D 방향 차이 10.68°(원래 0.61°)이며 B1 고정 2영상에서도 같은 방향의 변화가 확인되었다. 단순 위축 추정이나 렙 내 invalid 마스크만의 문제로 설명되지 않는다. 실제 해부학적 관절 정의 차이는 아직 미확인이다.
- 실제 V 학습 입력을 원근·fitted 관절 offset·잡음 잔차로 분해한 결과, 측면 목표−입력 XY 기울기 차이는 squat +6.68° / row +8.33°이고 그중 관절 offset 성분 중앙값이 +6.37° / +7.22°였다. 원근 성분은 +0.007° / +0.051°로 작다(단계별 중앙값 합산 불가). **학습에서 정의 변환을 감독하는 것은 확인했지만, 이것이 Exercise3D 약 10° 편향의 완전한 원인이라는 증명은 아니다.** B1에도 현상이 있어 V 단독 원인으로 단정하지 않는다. 예정 C3 레시피·사전 등록 기준은 그대로다.
- **표기 수정**: Exercise3D의 `up_c`는 여러 카메라의 수직축 평균에서 추정했다. 실제 중력을 측정한 정답이 아니다. 아래 진단과 기존 Exercise3D 몸통 표는 **추정 위축 기준·의사 3D 라벨 비교**다. Fit3D 실제 중력과 구별한다.
- 고정 입력 `xs-heldout-inputs-20261020/E_heldout_h26.npz`(P2/P3, 9시퀀스)에 원래 XS와 C1을 비교하고 B1은 원인 분리를 위해 측면 2영상만 확인했다. 정확히 같은 27프레임 입력 창·L=5·행21을 쓰고, 출력 시점만 매 5프레임으로 고정 표본 추출한다. CPU 2스레드이며 새 학습·튜닝은 없다. 입력 2D와 3D XY 방향은 정상 원근투영에서도 달라질 수 있으므로 방향 차이 자체를 결함으로 판정하지 않는다. 기존 전체 프레임 사전 등록 평가를 대체하지 않는다.
- 조사량: 위축과 무관한 예측/라벨 몸통 벡터각, XY 방향 오차와 깊이 성분, signed inclination bias, 카메라-위/추정-위/공통 축 ±10° 고정 회전 민감도. 몸통은 `양쪽 어깨 중간 − 양쪽 엉덩이 중간`이다. 합성 root→thorax와 혼동하지 않는다.
- 기존 E 점수는 팔다리 위치 오차에만 `fmask`를 적용하고 각도에는 적용하지 않았다. 원본 canonical 3D의 엉덩이·어깨 valid mask를 별도 확인하고, 원래 렙 프레임/팔다리 유효/몸통 유효/둘 다 유효를 분리한다.
- 코드 `scripts/finetune3/xs_torso_diagnostic.py`. 원인 규명 전에는 라벨·중력 추정·실제 모델 변형 중 어느 것도 원인으로 단정하지 않는다. C1 몸통 계열 규칙 보류와 기존 A 불통과는 유지한다.
