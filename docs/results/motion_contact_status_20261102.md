# Motion Prediction·Adaptive Contact 검증 상태

2026-11-02. 원본 MotionAGFormer-XS는 유지한다. 기존 학습 없는 A–H 실험과 이번 실기기 완료 기록을 구분해 정리했다. 보정 기능을 기본 활성화할 근거는 아직 부족하다.

기존 실험 소스·수치는 `ai/motion-contact-20261020`의 `docs/results/motion_contact.md`와 해당 프로토콜·원본 산출물에 보존돼 있다. 최신 앱 후보에는 별도의 푸시업 2D 지지 범위 실험이 있으며 기본 OFF다. 이 둘을 동일 알고리즘이나 실제 바닥 접촉 검출기로 부르지 않는다.

| 요구 질문 | 현재 근거와 결론 |
| --- | --- |
| 1. 일시적인 관절 오류의 원인 | 2D 가림·좌우 혼동·시점/입력 분포·관절 정의·시간 구간 문제가 함께 있다. 높은 2D 점수에서도 3D 각도 오류가 관측돼 confidence만으로 정확한 관측을 확정할 수 없다. 모든 오류의 단일 원인을 찾은 것은 아니다. |
| 2. 과거 속도로 손목을 얼마나 예측할 수 있나 | 짧은 구간의 후보 생성에는 쓸 수 있지만 방향 전환·장기 가림에서 외삽이 실패한다. v4는 오래된 예측을 만료시킨다. 실제 손목 정확도 개선을 일관되게 입증하지 못했다. |
| 3. Kalman이 smoothing보다 나은가 | 모든 조건에서 우월하지 않다. 깨끗한 입력·손상 입력·RGB 가림을 따로 봐야 하며 한 조건의 jitter 감소를 성공으로 채택하지 않는다. |
| 4. SMPL 뼈 길이가 개선하는가 | RGB 유래 개인 프로필을 사용한 기존 비교의 평균 차이는 작았고 G/H 실패를 해결하지 못했다. 캘리브레이션은 오차가 있는 추정이며 정확한 상수로 강제할 근거가 아니다. |
| 5. 운동 단계가 방향 전환을 해결하는가 | 관측된 단계만 쓰는 H를 비교했지만 일관된 해결은 입증하지 못했다. 불확실한 단계를 정답처럼 주입하지 않는다. |
| 6. 손·발 지지점은 얼마나 안정적인가 | 고정 카메라 2D의 짧은 지지 범위는 사용할 수 있으나 일반 사용자 실제 접촉/미세 손 회전까지 검증한 수치는 없다. root-relative 발목을 지면 좌표로 고정하지 않는다. |
| 7. Anchor가 유효한 조건 | 같은 사람·고정 카메라·안정된 관측·짧은 가림·유효한 좌표계가 필요하다. 카메라/스탠스/그립 이동이나 장기 가림에서는 해제·재획득·보류가 필요하다. |
| 8. 실제 지지점 변경을 감지하는가 | 합성 상태 전이와 관측 우선·만료 계약을 검사했다. 실제 다양한 지지점 이동의 성공률을 검증한 것으로 확대하지 않는다. |
| 9. 비정상적인 점프가 얼마나 줄었나 | 전체 성공 수치가 없다. 기존 v4 clean MPJPE 146.839→146.758mm, 손상 관절 336.020→365.075mm로 악화, RGB 가림 319.747→318.150mm의 작은 차이였다. |
| 10. 나쁜 자세를 정상화하지 않는가 | 신뢰한 관측을 그대로 통과시키고 큰 보정·만료 예측을 평가에서 보류한다. 그러나 실제 오류의 독립 라벨이 없어 false negative가 늘지 않았다고 증명할 수 없다. |
| 11. 3D PT 신뢰성이 향상됐나 | 기능·근거 표시 오류는 수정 중이지만 보정 정확도 개선의 채택 기준은 충족하지 못했다. 정상 자세 검증과 반복 완료를 분리한다. |
| 12. iPhone 비용은 얼마인가 | 실제 motion18 로그 18/18 검증 완료. H-light/detail 모듈 p95 약 0.0204/0.0211ms다. 후속 제약·평가 게이트·로깅을 제외한 타이머여서 전체 앱 추가 지연으로 표현하지 않는다. |

실기기 detail 4,533프레임의 예측 관절 표본 1,377개 중 확정 평가에 유효한 것으로 표시된 것은 0개였다. 이는 보류 정책이 동작한 증거이며 예측 위치가 맞았다는 증거가 아니다. 원본16회와 서명 갱신 후2회는 약6일 떨어진 측정이므로 모드별 인과적 속도 우위를 주장하지 않는다.

폰 측정·서명·보존의 정확한 범위는 [11월2일 검증 기록](deep_analysis_status_20261102.md)에 있다. 학습·모델 교체·실험 기본값 변경은 없었다.
