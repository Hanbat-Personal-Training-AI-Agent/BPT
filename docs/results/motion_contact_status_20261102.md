# Motion Prediction·Adaptive Contact 검증 상태

**11월 4일 후속:** 마지막 수락 시각의 2D/3D 좌표를 같은 골반 기준으로 비교하는 별도 후보를 구현하고 [72스트림·5정책 비교](motion_anchor_alignment_results_20261104.md)를 완료했다. 정상 입력의 전체 오차는 기존 G/H보다 약 0.025mm 줄었으나, 키포인트 손상과 RGB 가림의 전체 오차 및 판정 가능 비율은 나빠졌다. 기본 적용하지 않는다. 기존 원본/G/H 수치는 같은 배열과 분모에서 재현됐으며, 보류된 관절도 전체 오차에 포함했다. 별도로 부모·자식 관절의 서로 다른 관측 시각을 뼈 길이로 사용하는 결함은 합성 재현했으며, 이 첫 비교의 수정 범위에는 넣지 않았다. 현재 후속 구현·검증 상태는 [통합 기록](bpt_completion_20261104.md)에 이어 적는다.

같은 날 그 뼈 길이 결함도 독립 후보로 구현해 [같은 72스트림·9정책 비교](motion_edge_alignment_results_20261104.md)를 마쳤다. 판정 가능 비율은 높아졌지만 목표 관절 오차와 움직임 억제의 상충이 남아 채택하지 않는다. [7개 관절각·시간 미분·불확실성·지지점 속도 추가 분석](motion_edge_supplement_results_20261104.md)도 완료했으며, 전반적인 자세 정확도 개선이나 불확실성 확률의 신뢰성을 입증하지 못했다. 소스와 결과는 실험 브랜치에 보관하고 앱의 기본 보정은 계속 OFF다.

**11월 3일 후속:** 보관된 추정기를 현재 XS 파이프라인에 기본 OFF 관찰 모듈로 [이식했다](motion_observer_port_20261103.md). 실제 저장된 3영상 입력의 [9방식 27행 재생](motion_observer_saved_replay_20261103.md)과 [고정 카메라·온라인 비율을 명시한 별도 H 비교](motion_observer_fixed_online_h_20261103.md)를 완료했다. 푸시업 17프레임의 후보가 달라졌으며, [실제 RGB와 대응한 손목 점프](wrist_observation_20261102.md)는 줄었지만 가려진 관절의 실제 위치를 확인한 결과는 아니다. 원본·신뢰한 관측의 그대로 통과·예측 관절 보류·기존 평가 결과 불변을 검사했다. 이후 [최종 v5 기기 시험 6개와 원복](current_phone_validation_20261103.md)을 완료했다. H의 동일 실행 522행을 원본과 대응했고 예측 관절 18개는 모두 평가 무효였다. 아래 과거 motion18 모듈 속도를 새 이식 버전의 전체 추가 지연으로 대신하지 않는다. [계정/촬영에 묶인 개인 캘리브레이션 연결](account_motion_profile_bridge_20261103.md)도 구현·검사했지만 실제 적격 개인 프로필을 적용한 정확도 검증은 아니다.

2026-11-02. 원본 MotionAGFormer-XS는 유지한다. 기존 학습 없는 A–H 실험과 이번 실기기 완료 기록을 구분해 정리했다. 보정 기능을 기본 활성화할 근거는 아직 부족하다.

기존 실험 소스·수치는 `ai/motion-contact-20261020`의 `docs/results/motion_contact.md`와 해당 프로토콜·원본 산출물에 보존돼 있다. 최신 앱 후보에는 별도의 푸시업 2D 지지 범위 실험이 있으며 기본 OFF다. 이 둘을 동일 알고리즘이나 실제 바닥 접촉 검출기로 부르지 않는다.

## A–H의 정량 근거

원본 `ai/motion-contact-20261020:3d00335`, `docs/results/motion_contact.md`의 완료 결과를 함께 읽기 위한 표다. **이번에 새로 실행한 결과가 아니다.** A–F/HOLD는 v3의 고정 결과, G/H는 동일 입력에 예측 만료를 추가한 v4 결과다. clean은 별도 검증 60스트림·568,004관절/프레임이며, 손상 실험은 한 피험자·3운동·2카메라의 6스트림이다. 모든 방법은 기존 L5 시점이 같고 추가 미래 프레임이 없다. 위치 오차 단위는 mm다.

2D 손상은 XS를, RGB 가림은 RTMPose→XS를 실제 재실행했던 실험이다. RGB 조건은 원 detector box를 유지했으므로 detector의 가림 강건성을 포함하지 않는다. 목표 관절 분모는 각각 544/536개다. GT 깊이는 최종 mm 채점에만 사용했으며 추정기의 위치·단계·앵커·뼈 길이 입력으로 사용하지 않았다. RGB-SMPL 프로필에는 평가 시퀀스의 사진도 포함돼 독립 캘리브레이션 검증으로 해석할 수 없다.

이 표에서 Kalman과 뼈 길이는 단순 smoothing이나 원본을 일관되게 개선하지 않았다. H는 G보다 작은 차이를 보였지만 손상 관절 오차는 원본보다 크다. 실제 이동 억제 proxy도 clean에서 A 25.057%, G 25.624%, H 25.605%였으며, 이 비율은 전문가 오자세 누락률과 다르다. 따라서 jitter 감소·일부 평균 개선·낮은 연산 비용만으로 채택하지 않는다.
