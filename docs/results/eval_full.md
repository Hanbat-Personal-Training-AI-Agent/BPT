**이 표에서 읽을 것**
- **3D 정확도는 XS 미세조정에서 거의 다 온다.**

- **C3 vs C1·C2**: Fit3D 사선 실험 A에서는 C1·C2가 MPJPE 1.1–1.2 mm 작다(CI가 0을 겨우 벗어남). PA는 C3가 0.3–0.5 mm 작다.

각주
1. S0는 2D 규칙만 쓴다. Fit3D·공개 세트에서 2D 규칙을 돌리는 Python 미러가 없고, Fit3D는 Mac(Swift pose-replay)에 갈 수 없다. 기기 D1 4클립의 2D 경고(로그만)는 4절에 적었다.
2. 렙은 2D 상태기계가 센다. 3D 구성과 무관하다. 기기 D1–D4·C3 실행 4클립 × 2회에서 렙은 구성마다 같았다(정면 푸시업만 COCO17 11 vs Halpe26 10, 정답 10).
3. `BPT_CAMERA_3D=0` 경로에는 판정 지연 계측이 없다(기기 에이전트 확인). FPS·드롭·CPU만 있다.
4. 공개 held-out COCO17 3D 행은 이번에 다시 돌리지 않았다(rules-calib는 Halpe26 입력만 최종 분석함).
5. D3 = m Halpe26 + X0 + clamp + 체형 P1(기기).
6. C3 테스트 빌드(dfe4b6c + finetune3 Halpe 고유점 매핑 패치, 비상업 패키지) + 체형 P1. 앱 Swift 출력은 PyTorch C3와 퍼짐의 0.21–0.23% 차이(finetune3 c6af754).
7. C1·C2·B1은 C3와 같은 아키텍처·같은 Core ML 변환기라 그래프가 같다고 본다. C1 패키지만 Home에 있고, 기기 실행은 없다.
8. D4 = D3 + L=3(X0 가중치). Fit3D L=3 값은 C3로 잰 것.
9. C4 = h26ft 출력으로 다시 학습한 Halpe 고유점 XS(finetune3 §1.4, `xs-C4/xs.pth` sha256 `66e497ff…e3d3`, 학습 10-22 13:50 종료). 2D h26ft는 finetune3 규칙 5·6 불통과(흔들림 합성 가짜 렙 2, 셋업 알람 증가)가 확정이라 제안 후보가 아니다. Fit3D 실험 A 2D 좌우 바뀜은 h26ft가 무릎 0.03%·발목 0.09%로 가장 작다(h26ft는 Fit3D s03·s04로 학습, 검증 s07–s11과 피험자 분리). Home `eval-full/C4_h26ft/`, `summary_c4.md`. C4 자체의 사전 등록 판정은 finetune3 몫이다.

**절제에서 읽을 것**
- **미세조정 XS 위에서는 3D 제약이 정확도를 올리지 않는다.**
  - 원래 XS 앱 경로에서는 사람별 뼈 길이가 PA −1.87 mm였다(lift-refine R-BONE 통과, 같은 숫자를 이번에 재현함). C3에서는 반대로 +0.4–0.5 mm다.
  - 모캡 길이(상한)조차 MPJPE −0.4 mm다. C3 출력의 팔다리 비율이 이미 사람답다는 뜻으로 본다(가설).
  - 제약의 역할은 정확도가 아니라 **안전장치**다. 내각 한계는 불가능 각 0.07%를 0으로 만들고, 무릎 고정은 원래 XS에서만 걸린다(1.05% → 0).
- **적응형 가림 제약은 깨끗한 입력에서 손해다**: +0.46 mm, 무효 관절 1.25%.
  - 가림 상황 이득은 setup-constraint가 원래 XS로 쟀다: 합성 가림 −6.95 mm(−2.5%), 사전 등록 목표 5% 미달.
  - C3에서는 가림 이득을 재지 않았다.
- **L=3**은 C3에서 MPJPE +0.22 mm(원래 XS에서는 +0.49 mm)를 대가로 판정을 67 ms 앞당긴다. 각도 차이는 신뢰구간이 0을 포함한다.
- **A8 손목 바닥 고정**: setup-constraint 10절의 값이다(원래 XS, Halpe26 실험 A, 같은 Fit3D 검증 푸시업 20스트림, **다른 기준 구성**).
  - Fit3D 화면 손목 날아감 1.44 → 1.43%, 손목 3D 221.7 → 221.6 mm, 규칙 발동이 바뀐 렙 0/100.
  - Exercise3D 앱 경로(m Halpe26)에서는 화면 손목 1-아래팔 이탈이 1.01 → 0.35%다.
  - C3로는 재지 않았다. 손목 고정은 2D만 바꾸므로 XS가 달라도 화면 효과는 같다. 3D 효과는 미측정이다.

### A. 요약
