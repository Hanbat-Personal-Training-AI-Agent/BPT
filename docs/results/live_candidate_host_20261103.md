# Live experimental candidate host proof — 2026-11-03

The explicit experimental candidate branch now consumes normal in-memory lifted camera frames without terminal capture or a terminal logger. `Frame.live` carries the original source clock, source index, epoch, raw XS arrays, assessment arrays, confidence and invalid mask into one `CoachingCandidateRuntime.Processor` call. Terminal logging reuses that result; it does not advance candidate windows a second time. Compact-payload validation happens before presentation, and a failure produces an explicit error and clears any displayed proposal.

Both existing experimental flags and an explicit experiment declaration remain required. Default settings, ordinary coaching and pose output are unchanged. Candidate values, targets, registry and inference are unchanged. Video frames without the existing log-owned clip-index mapping remain withheld; no replacement video index is invented. The normal camera path uses its actual capture index and does not need that mapping.

A separate locked generation is stamped before asynchronous XS processing. Stop, set end, superseded set, background and source restart invalidate it; old callbacks cannot deliver proposals into the new generation. Foreground starts a new generation only while the camera is running and the set is active. End-set invalidation deliberately prevents subsequent asynchronous/flush callbacks from presenting or evaluating live candidates. Original terminal frame evidence and ordinary evaluation still run. The retained-data replay below explicitly evaluates all 15 historical flush rows as withheld observations; it does not assert that a stopped live session now logs candidate payloads for those rows.

The presenter clears the actual previous capture/proposal/source identity, so the receiver can remove the banner before accepting a new source. Phase now participates in presentation binding. Forced resets also clear cadence state after an earlier unknown observation removed the banner. Missing geometry, malformed geometry, unknown phase/side and source/rotation transitions are covered by native tests.
