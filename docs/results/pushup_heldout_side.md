# 측면 푸시업 검증(P1 아닌 사람) — 트랙 pushup-heldout (D-T3-08)

측정만 함(규칙·임계값 변경 없음). 앱 기본 = RTMPose-m COCO17, crop 입력(D-T3-05). 지금까지 측면 푸시업 렙 수치는 Exercise3D P1 한 사람(조정용)뿐이었다.

**용어**
- 렙 정확도 = (정답 렙 − 놓친 렙) ÷ (정답 렙 + 더 센 렙). 놓침과 추가를 둘 다 깎는다(three-ex·rep_validation과 같은 정의). 100%면 모든 렙을 정확히 셈.
- 놓침(−) = 정답 렙인데 앱이 안 센 것. 추가(+) = 정답에 없는데 앱이 센 것.
- 구간안 + = 추가 중 세트 구간(첫 렙 시작–마지막 렙 끝) 안에서 생긴 것. 구간 밖 추가는 엎드리기·일어서기 동작(D-T3-02의 남은 문제).
- "세트 구간만" 정확도 = 구간 밖 추가를 빼고 계산한 값. Exercise3D처럼 플랭크에서 시작해 플랭크에서 끝나는 세트에 해당.
- 조정(tune) = 규칙을 맞출 때 본 사람(Fit3D s03·s04·s05), 검증(held) = 안 본 사람(s07–s11, three-ex가 결과 보기 전에 고정한 분할).

## A. Fit3D 모캡 → 가상 측면 카메라 (합성 투영, 검출기 없음)

> **합성 투영, 검출기 없음(synthetic projection, no detector).** 실제 영상·실제 RTMPose 출력이 아니다. 2D 점은 3D 모캡을 투영하고 Exercise3D에서 잰 RTMPose 오차를 덧붙인 것이다.

방법 (`scripts/eval_pushup_virtual_side.py`):
1. **COCO 정의 보정**: Fit3D `joints3d_25`는 관절 중심이라 COCO 어깨·엉덩이와 위치가 다름(D-C-02). 조정 피험자 s03–s05의 실제 영상 4대 × 3명에 RTMPose-m을 돌린 2D와 모캡 투영(왜곡 포함)의 차이로, 부위별 3D 오프셋 하나씩(몸 좌표: 몸통 축·바깥쪽·앞쪽, 좌우 대칭)을 최소제곱으로 맞춤(잘라낸 이상치 3회 반복). 결과(m, 몸통 축/바깥/앞): 엉덩이 −0.020/−0.047/−0.068(중앙 오차 16.8 → 6.3 px), 어깨 0.003/−0.002/−0.034(11.3 → 8.5 px), 코 0.087/0.014/0.023(17.8 → 10.0 px), 팔꿈치·손목·무릎·발목은 3 cm 이하. 눈·귀는 머리 표지(9·10번)에서 만든 근사(푸시업 렙 판정에 안 쓰임).
2. **가상 카메라**: 모캡 50 → 30 fps. 720×1280 세로, f = 913 px(iPhone 1× 16:9 세로 짧은 변 화각 43°), 바닥에서 0.5 m 높이, 몸 중심에서 수평 3.5 m(3.0 m에서는 몸 일부가 화면 밖 — 최대 12% 프레임), 몸 중심을 바라봄. 몸 왼쪽·오른쪽 각각, 순수 측면에서 머리 쪽으로 0/20/40° 회전. three-ex 정의로 다시 잰 시점 각도 0/19–21/37–43°. 세트 구간 전 프레임에서 몸 12점이 모두 화면 안.
3. **오차·신뢰도 모델**: Exercise3D 측면(≤45°) 푸시업 9영상(P1)에서 RTMPose-m 키포인트 − Sapiens2 2D 라벨(의사라벨, 정답 아님; 1.5배 스케일)을 몸통 길이로 나눈 잔차와 RTMPose 신뢰도를 **영상 통째로** 보관(시간 상관·좌우 뒤바뀜·관절 간 상관 유지). 머리 방향 = +x, 카메라 가까운 쪽 = 왼쪽 칸으로 맞추고 전체 평균은 뺌(평균 치우침은 1단계 오프셋이 담당). 가상 각도마다 각도가 가장 가까운 Exercise3D 영상 3개를 시드 0–2로 쓰고 시작 프레임은 무작위. 크기: 가까운 쪽 잔차 중앙값 몸통의 0.013–0.048, 먼 쪽 0.055–0.18(먼 발목 p90 0.51), 신뢰도 중앙값 가까운 쪽 0.62–0.95, 먼 쪽 0.35–0.81.
4. **정답**: `rep_ann` 경계(사람마다 5렙) + 3D 어깨 높이 골(40/40 일치). 매칭은 three-ex `run_eval.match`와 같음.
5. pose-replay `--keypoints-csv`(규칙 = integration/ai `ab07ba5`)로 재생. 1명 × 6시점 × (깨끗 1 + 오차 3).
