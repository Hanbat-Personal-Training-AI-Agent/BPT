# 기존 캘리브레이션 영상·실기기 기록 재검증

2026-10-26. 사용자의 “우리 썼던 캘리브레이션용 영상” 지시에 따라 기존 영상과 폰에서 회수한 저장 결과를 검증했다. 새로운 사람 촬영을 요구하지 않았다. 이번 단계는 기존 자료 감사이며 새 카메라 실행으로 세지 않는다.

## A. 확인한 사실

- 기기에서 보존한 94개 파일의 SHA256이 모두 일치했다. 원본·사진·관절 배열은 Mac의 `~/bpt-data/device-preserve-20261026/`에만 보존했다.
- 캘리브레이션 세션 10개 중 **9개는 네 방향 완료**, 1개는 두 방향만 저장됐다. 완료 플래그·방향 중복·사진 존재·JPEG 헤더와 선언 크기 일치·업로드 영수증의 세션 일치 검사를 통과했다. 총38장에 대응하는 COCO17 관절646개는 모두 유한하고 각 사진의 픽셀 범위 안에 있었다. 사진 위 정렬의 시각적 정확도를 검증했다는 뜻은 아니다.
- 완료9개 중8개는 서버의 `accepted` 영수증이 있고, 1개는 영수증이 없다. 접수 영수증만으로 서버 체형 분석 완료를 주장하지 않는다.
- 별도로 `final_1602` 기기 로그에서는 네 방향 촬영 완료, 서버 `done`31.0초, GLB248,768바이트 다운로드31.5초, `mesh prepared true`를 확인했다. 총31초는 작업 조회 기준이며 촬영 시작부터의 전체 시간이 아니다.

## B. 원인과 한계

원본은 사선 자세를0.3–0.6초에 지나가므로 기존0.8초 유지 조건을 충족하지 못한다. slowdiag는 기존 데모에서 사선 구간의 시각만0.25배 속도로 늘린 별도 시험 입력이다. 프레임 수는658개로 같지만 **원본 속도에서 네 방향 성공한 결과가 아니다**. 캡처 순서도 영상의 실제 회전 순서가 앱 안내와 다르다. 모든 방향을 어떤 순서로든 확보하는 엔진 동작과 안내 순서를 분리한다.

저장된38장의 내부 파라미터는 모두 `fov_estimate`, fx=fy=0의 명시적 fallback이다. 실제 카메라가 제공한 초점거리 측정값이 아니다. 업로드는 이 fallback을 허용한다. 절대 신체 길이 정확도나 깊이 정확도를 이 기록만으로 입증하지 않는다.

## C. 이전 상태 보고 정정

10/21 인계의 “폰 파일 서비스 대기”와 10/23 오전의 “사람4분 촬영 대기”만 읽으면 이후 진척을 놓친다. 10/23 오후에는 사용자 영상 입력을 지원하는 trial 앱에서 체형 촬영→업로드→완료→메시 준비까지 실제 실행됐다. 이번에 그 기록을 확인했다.

다만 영상 모드가 폰 기울기를 `still`로 대체하므로, **실제 카메라 버퍼 회전·중력 부호가 해결됐다는 증거는 아니다**. 이 한계를 숨기려고 같은 영상을 다시 돌려 새 카메라 성공이라고 쓰지 않는다.

## D. 자료 신뢰성

- 원본 사진·영상·개인 관절 좌표를 git에 넣거나 외부로 전송하지 않았다. 출력은 개수·시각·해시·검사 결과뿐이다.
- 기기 `calibration_diag` 폴더는 비어 있었다. 기존 실행에 진단이 켜졌다는 증거가 없으므로 카메라 회전 메타데이터를 추정해 채우지 않았다.
- 네 방향 완료는 엔진이 받아들인 촬영이라는 뜻이다. 사람이 방향과 자세를 독립 라벨링한 정확도 시험은 아니다.
- 데모의33개 렙은 운동 기능 기록이다. 새 심층분석 API의 전체 앱 흐름 완료와 혼동하지 않는다.

## E. 재현

도구: `scripts/audit_saved_calibration.py`. 영상은 ffprobe로 메타데이터만 읽고, 사진은 해시와 JPEG 헤더만 읽는다. 사진을 렌더링하거나 내보내지 않는다. 기존 출력 덮어쓰기를 거절한다. 해시 불일치·완료 세션 방향 누락·잘못된 관절 형식·비유한 관절·사진 크기 불일치·영수증 세션 불일치가 있으면 비정상 종료한다.

## F. 현재 권고

기존 slowdiag는 캘리브레이션 앱 흐름과 서버 연동의 회귀 입력으로 계속 쓸 수 있다. 원본은 짧은 유지 구간을 성공 처리하지 않는 음성 대조 입력으로 함께 유지한다. 사용자가 요청한 심층분석 전체 흐름은 별도 앱·서버 수정과 시험에서 확인하고, 캘리브레이션 성공 기록으로 대신하지 않는다.

## G. 남은 확인

기존 영상 기반 검증은 새로운 사람 촬영 없이 진행 가능하다. 실제 카메라 버퍼·중력·현장 네 방향 촬영 검증은 영상 모드로 대체할 수 없는 별도 항목이다. 이번 감사는 그 물리적 측정이 완료됐다고 표시하지 않는다.
