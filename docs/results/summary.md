# 결과 요약 (발표용)

기준: `integration/ai`. 빈칸(—, "대기")은 해당 트랙 결과가 병합되면 채웁니다. 각 수치의 근거 파일과 결정은 `docs/decisions.md`.

용어
- **렙 정확도** = (정답 렙 − 놓친 렙) ÷ (정답 렙 + 추가로 센 렙). 100%면 하나도 안 놓치고 더 세지도 않음.
- **조정용(tuning)**: 규칙·임계값을 정할 때 본 데이터. **검증용(held-out)**: 사람(피험자) 단위로 떼어 두고 조정에 안 쓴 데이터. **실제 영상**: 사용자가 직접 찍은 영상(최종 시험).
- **측면(±40°)**: 몸 옆 40° 이내 카메라. **검출률**: 틀린 자세 렙 중 경고가 난 비율. **오경보율**: 정상 렙 중 경고가 난 비율.
- **PCK**: 예측 관절이 정답에서 일정 거리(몸 크기 비례) 안에 든 비율. **MPJPE**: 3D 관절 위치 오차 평균(mm).
- Exercise3D 정답은 Sapiens 기반 삼각측량 라벨(`not_ground_truth`, 검토 전)이라 "정답"도 오차가 있을 수 있음.

## 5. 앱 연결 (트랙 E)
- onFeedback `{key, n?, scope:"rep"|"set"}`: 기본값에서 실제로 나가는 키는 그대로(setup_full_body, tracking_lost, 로우 setup_side_view).
- 음성: 네이티브 WorkoutVoice가 Flutter가 답으로 준 대사만 말함(mp3 `assets/kori_voice/<key>[_<n>].mp3` → 없으면 기기 TTS). mp3는 팀원이 직접 생성해 넣음(이름 규칙 `docs/handoff/kori_voice.md`).
- onSetEnd `{setIndex, videoLocalPath, worstJoint}`: worstJoint는 켜진 경고 키만 보므로 지금은 항상 null.
- 벤치·데드: 평가기가 자기 경고 트래커를 가짐(트랙 G) — setup_full_body·tracking_lost만 전달, 새 키 6개는 판정·로그만.
- 세트별 녹화(720p H.264, 최근 20개 보관)는 **기본 꺼짐** — 실기기 FPS 감소 ≤10% 확인 후 켬.

## 7. 한계
- **조정·평가 데이터 겹침**: Exercise3D에 피험자 ID가 없어 영상을 보고 사람을 나눔(P1 조정용, P2·P3 검증용, 추정). 푸시업은 전부 P1이라 검증 세트가 없음. 사람 재확인 경계값(D-B-03)은 검증 영상까지 보고 정함.
- **정답 라벨 미검토**: Exercise3D 렙 정답은 자동 삼각측량(검토 전), 2D 정답은 Sapiens2 출력(의사 정답).
- **측면 컷오프**: 로우 0.66(crop)은 40° 근처 데이터가 없어 미검증이고, 정면 스쿼트 영상 비율이 0.64–0.67이라 정면 촬영이 측면으로 판정될 수 있음. 푸시업 1.0은 40°와 48°를 못 가름.
- **자세 경고 꺼짐**: 틀린 자세 데이터가 없어 검출률을 모름. 임계값은 전체 프레임 입력 p99라 crop 입력에는 느슨함.
- **기기 속도 일부만 측정**: 2D 모델 단독 추론은 iPhone 17에서 잼(D-C-05). crop·평가기·3D·녹화를 포함한 앱 전체 FPS는 아직 못 잼.
- **벤치·데드는 대리 입력**: 원본 영상이 없어 앱 RTMPose가 아니라 Sapiens2 2D 키포인트로 잼. 누운 자세 측면 RTMPose(한쪽 팔 허용, D-G-02)는 미검증. 데드는 정면 카메라 지원 안 함(정면 9.1%), 마지막 렙은 바를 내려놓을 때 셈.
- **2D로 안 보이는 것**: 허리 굽힘, 버트윙크, 견갑 후인, 벤치 바 경로·아치는 다루지 않음.
- **Fit3D**: 측면 카메라 없음(58–74°), 비상업·단일 사용자 라이선스 → 학습 가중치는 캡스톤 용도만(미세조정 모델은 채택 안 함).
- **준비 자세 확인 꺼짐**: 세트 전 바 들기로 1렙이 더 셀 수 있음(Exercise3D 1건).
- **캘리브레이션**: 기준 메시가 정답이 아니고(단안 추정 키), β10이 사람마다 ≈+2로 일정(변환 치우침, 추정). SMPL 라이선스상 비상업만, 상업화 땐 별도 라이선스.
