# 결과 요약 (발표용)

기준: `integration/ai`. 빈칸(—, "대기")은 해당 트랙 결과가 병합되면 채웁니다. 각 수치의 근거 파일과 결정은 `docs/decisions.md`.

용어
- **렙 정확도** = (정답 렙 − 놓친 렙) ÷ (정답 렙 + 추가로 센 렙). 100%면 하나도 안 놓치고 더 세지도 않음.
- **조정용(tuning)**: 규칙·임계값을 정할 때 본 데이터. **검증용(held-out)**: 사람(피험자) 단위로 떼어 두고 조정에 안 쓴 데이터. **실제 영상**: 사용자가 직접 찍은 영상(최종 시험).
- **측면(±40°)**: 몸 옆 40° 이내 카메라. **검출률**: 틀린 자세 렙 중 경고가 난 비율. **오경보율**: 정상 렙 중 경고가 난 비율.
- **PCK**: 예측 관절이 정답에서 일정 거리(몸 크기 비례) 안에 든 비율. **MPJPE**: 3D 관절 위치 오차 평균(mm).
- Exercise3D 정답은 Sapiens 기반 삼각측량 라벨(`not_ground_truth`, 검토 전)이라 "정답"도 오차가 있을 수 있음.

- "조정용" 칸은 같은 데이터로 규칙을 고치고 같은 데이터로 잰 값이라 실제보다 좋게 나올 수 있음(과적합 위험). 검증용 칸이 채워져야 일반화 성능을 말할 수 있음.
- 진단에 안 쓴 squat_03(정답 2렙): 수정 전 1 / 2 → 수정 후 2 / 2.
- 가짜 렙(움직임 없음): 서서 흔들림 합성 88건 + 더미 영상 6개 → **0렙** (스쿼트·로우 평가기, 두 모델).
- 후면 카메라 로우: 8/8 "측면 아님" 판정 → 렙 안 셈 + setup_side_view 안내.
- Fit3D(사선 58–74°만 있음, 회귀 확인용): 스쿼트 12영상 정답 60렙 중 COCO17 15→48, Halpe26 23→59렙. 정답 구간 안 추가 렙 0.

## 5. 한계
- **조정·평가 데이터가 같음**: 지금 수치는 Exercise3D 13세트로 규칙을 고치고 같은 데이터로 잼. 사람 단위 검증용과 사용자 영상 결과가 필요.
- **정답 라벨 미검토**: Exercise3D 렙 정답은 자동 삼각측량(검토 전).
- **측면 컷오프**: 로우 0.56은 40° 근처 데이터가 없어 미검증, 푸시업 1.0은 40°와 48°를 못 가름.
- **자세 경고 꺼짐**: 틀린 자세 데이터가 없어 검출률을 모름. 정상 기준 p99 임계값만 있음.
- **2D로 안 보이는 것**: 허리 굽힘, 버트윙크, 견갑 후인, 벤치 바 경로·아치는 다루지 않음.
- **Fit3D**: 측면 카메라 없음(58–74°), 비상업·단일 사용자 라이선스 → 학습 가중치는 캡스톤 용도만.
- **준비 자세 확인 꺼짐**: 세트 전 바 들기로 1렙이 더 셀 수 있음(Exercise3D 1건).
- **캘리브레이션**: 사람이 달라도 β(체형 계수)가 거의 0, 워커가 죽으면 job이 running으로 남음.
