Common setup/encouragement is separate: setup_full_body uses45missing-required2D frames before reps; tracking_lost uses30missing frames after start and defers while a rep is open. setup_side_view is first-rep/row-session guidance. Required2D sets are selected-side shoulder/elbow/wrist/hip/ankle(pushup), shoulder/hip/knee/ankle(squat), shoulder/elbow/wrist/hip(row), confidence≥0.30. `praise_good` is generic encouragement; correction praise additionally needs the previously spoken rule assessed under current gate, full finite reference, enabled key and same3D/2D source. Neither establishes whole-form correctness.

Current speech call graph is concrete: `NativePoseWorkoutScreen._handleNativeCall` returnsnull to native; rep `_onNativeFeedback` calls `_speakFeedback → KoriVoiceService → bpt/kori_voice → KoriSpeaker` with the Dart text. `_onNativeSetSummary` updates recorded counts only. Native XS coordinates are H36M17 camera/model space (xright, ydown, zaway), pelvis-relative. Defaultup is camera−Y; CoreMotion mapping is opt-in/unverified, not default gravity alignment. Selected side is the higher mean confidence of **seven** body joints(ear through ankle), hysteresis0.08. It can switch per frame; the exported rep side is a majority. Deep instead fixes that side for the entire declared video_ms interval. Native confidence passes through COCO→H36M averaging/crop normalization; accepted hand-wrist XY replacement retains RTMPose confidence. Confidence is not3D accuracy or visibility truth.

Native 3D input accepts≥6COCO joints with confidence≥0.3; the27frame XS window uses lookahead5/cadence1. Constraint-invalid joints becomeNaN. Ok/partial frames can supply individual finite quantities; rep3D judgement requires≥50%usable samples overall. Per-metric aggregation uses finite/non-nil compactMap, without a per-rule complete-span coverage guarantee. Valid positive evidence with other missing quantities can be intentional; this is **not automatically a defect**. Existing guards/test coverage distinguish positive partial evidence from absent evidence/confirmed correction. Legacy judgement can use its unknown-view side fallback or available subset of a first3reference; assessed-for-praise/live overlay have stricter qualification. This audit does not declare that policy a proven bug or recommend blanket withholding of known-positive issues.

View policies differ: framefront is shoulderwidth/torsolength≥0.5; pushup/squat judge uses per-rep front fraction<0.5, with legacy defaultside when absent. Row uses its verified rolling session gate(0.66), else that fraction. Pushup counting's rolling cutoff is1.0, with min30/latest150frames/hysteresis0.03; countability is not posture eligibility. Live unknown view/baseline remains withheld; ordinary wrong-phase/known-view exclusions are inactive. Relative-zero styling is not whole-segment approval. Quiet delivery is not filtered from the color table. Squat hips-first color visualizes only torso rise, not its speed conjunction.

Deep fallback is **sevenCSV rows**, not four universally: four generic rules plus exercise-specific depth drift for squat/pushup/bench. Pushup/squat each have5applicable rules; actual row had4. Generic ROMdrop compares fullROM to first3median(>15°), symmetry compares primary-joint bilateral angle max difference(>15°), trunk_sway uses unsigned torso **standard deviation**(>8°), tempo uses ratio to first3median(>0.3). All four generic device keys are blank; evaluatedKeys counts mapped native keys, not all assessed metrics. Deep supports every required joint/frame at≥0.35 plus actualtracking and whole finite geometry; first3drifts are withheld. This is a different evidence policy, not stronger physical ground truth.

Only two existing scalar mappings are conditionally comparable: pushup_shallow↔pushup_depth_drift and squat_shallow↔squat_depth_drift, both current minimum angle − first3median >15° from rep4. Preconditions are common intervals/sample selection, stable side equal to manifest side, same nondegenerate joint triples, complete baseline and required observations, and explicit compatible view/source gates. Native atan2 and deepacos are mathematically equivalent interior-angle operators for those finite chains; different pose estimates are not GT. Native pushup's quiet delivery and all spoken/logged distinctions must remain intact. No default warning parity follows from matching a field name.

Other mappings are not equivalent. Native torso is signed pelvis0→thorax8 vs camera-up/hip-derived forward; deep torso uses midpointshoulders11/14−midpointhips1/4 versus world+Y and is unsigned. Native max−min39.9°, proposed P95−P05standard15° and deepstd8° are three contracts. Native valgus is a knee/ankle **gap** ratio, not bilateral angle difference. A single torso segment or predicted spine proxy is not measured lumbar curvature. Squat hips-first is hybrid3D angle plus absolute2D image heights/frame speeds because pelvis-relative3D hip height is zero. Root-relative headward wrist ratio and pelvis-relative bilateral wrist trajectory cannot establish physical palm/floor contact, anchorage, bar position or hand-under-shoulder geometry.
