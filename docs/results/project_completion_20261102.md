- 실제 관측을 우선하고 원본 XS 좌표·불확실성을 보존한다. 실제 잘못된 자세를 보정으로 정상화하지 않는다.

- 폰은 Wi-Fi만 사용한다. 로그인·개인 영상·측정 원본·사용자가 만든 ZIP을 보존한다. 기존 motion18 및 완료된 리포트 시험은 반복하지 않는다.
- 원래 작업 폴더의 사용자 변경 4개는 유지한다. 새 코드·시험 결과를 기존 완료 앱 또는 과거 실험 결과로 표시하지 않는다.

## 정확도 검증의 한계

기존 Fit3D 결과는 동일 환경의 관절·각도 비교이며 독립 전문가의 오자세 정답이 아니다. 평균 MPJPE 또는 jitter 감소만으로 PT 품질 향상을 선언하지 않는다. 현재 로우·푸시업 실패, 실제 요추 굽힘 관측, 실제 지지점 이동 감지, 장시간 가림의 오자세 누락은 별도 통과 근거가 필요하다.

현재 후보의 실험 코칭은 수행 방식·운동 단계·관측 근거가 없으면 보류한다. 구현 항목의 개수는 실제 검증된 자세 오류의 개수가 아니다. 앱에 없는 바벨 접촉 관측이나 미래 프레임, GT 각도를 입력으로 만들어 넣지 않는다.

## 추가 선택측 실험

[선택측 ablation](../deep_analysis/own_side_results_20261102.md)은 B/C 모델 자신의 보존된 2D 검출 신뢰도로 기존 선택 규칙을 적용했다. **20/20 영상·103/103 반복에서 기존과 같은 쪽**을 선택해 판정·오차 변화가 0이었다. 양측 결과 및 원래 GT 대상 고정/선택측 GT 변경 진단을 분리했고 4,632개 과거 값을 재현했다. 이 원인 가설은 기각했으며 새 보정으로 채택하지 않았다.

현재 서버와 과거 평가기의 규칙도 다르다. 과거 로우 경계 평가는 몸통 범위 39.9°이고, 현재 서버의 임시 규칙은 몸통 표준편차 8°다. 현재 소스에는 팀 카탈로그 CSV가 없어 명시적 placeholder 규칙이 사용된다. 따라서 과거 경계 실패율을 현재 서버의 동일 규칙 성능이라고 표현하지 않는다. 실제 전문가 라벨 평가를 준비하는 별도 도구를 추가할 예정이다.
