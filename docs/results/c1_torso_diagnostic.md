# C1 Exercise3D 몸통 오차 — 원인 분리 진단

2026-10-20 재개 후 조사. **결과를 본 뒤 원인을 좁히는 진단**이며 사전 등록 평가, 모델 선택, 학습 레시피를 바꾸지 않는다. C1의 기존 판정(A 몸통 4.48° > 4.3°, A′ 통과)과 채택 미결정 상태는 그대로다.

## A. 확인한 사실

### 1. 동일 입력에서 모델이 영상면 몸통 방향을 바꾼다

기존 `E_heldout_h26.npz`의 P2/P3 3시퀀스 × 3카메라를 원래 XS와 C1에 넣었다. **입력 2D·27프레임 창·L=5·출력 행21·라벨·카메라 좌표·위축이 모두 같다.** 출력 시점만 5프레임 간격으로 고정 표본 추출했다. 렙 안 유효 표본은 측면 726개, 정면 363개다.

몸통 = `양쪽 어깨 중간 − 양쪽 엉덩이 중간`. 아래 값은 **프레임 오차 중앙값**이며 기존 보고의 렙 극값 오차와 다른 통계다. Exercise3D는 의사 3D 라벨이고 위축은 카메라에서 추정했다.

| 진단량 (°) | 측면 원래 XS | 측면 C1 | 정면 원래 XS | 정면 C1 |
|---|---:|---:|---:|---:|
| 예측/라벨 몸통 벡터 사이 각도 — 위축과 무관 | 4.17 | 10.55 | 15.12 | 4.33 |
| 추정 위축 기울기 signed bias — +는 수직에서 더 기울어짐 | +0.13 | +9.60 | −14.68 | +2.07 |
| 추정 위축 기울기 절대 오차 | 1.89 | 9.60 | 14.68 | 3.23 |
| 예측/라벨 몸통의 XY 방향 차이 | 1.89 | 9.10 | 1.87 | 1.64 |
| 출력 3D의 XY 방향 / **입력 2D**의 몸통 방향 차이 | 0.61 | 10.68 | 0.65 | 1.18 |
| 라벨 3D의 XY 방향 / 입력 2D 방향 차이 | 1.87 | 1.87 | 1.88 | 1.88 |

따라서 측면 차이는 **위축 추정이나 깊이 성분만의 문제로 설명되지 않는다.** 같은 입력에서 출력 몸통의 XY 방향 자체가 미세조정 뒤 달라진다. 단, 원근투영된 입력 2D 방향과 카메라 좌표 3D의 XY 방향은 올바른 3D에서도 다를 수 있다. **입력→출력 XY 차이 자체를 결함으로 판정하지 않는다.** 이것이 실제 사람의 해부학적 몸통을 더 잘/못 나타내는지는 별도 문제다. 입력 2D와 출력 3D의 관절 정의가 다를 가능성도 남긴다.

카메라 수직축을 공통 위축으로 쓴 경우에도 C1 측면 각 영상의 절대 오차는 4.23–14.21°, 원래 XS는 0.74–3.82°였다. 공통 위축을 카메라 x/y/z 각각 ±10° 회전한 **미리 고정한 6개 민감도 조건**에서도 측면 각 영상의 C1 악화가 남았다. 유리한 위축을 선택하거나 보정값을 학습하지 않았다.

### 2. 이전 미세조정 B1에서도 같은 방향의 현상이 있다

위 결과 후 C1만의 현상인지를 확인하기 위해, 같은 입력·같은 시점의 측면 2영상만 B1으로 추가 계산했다. 각도를 맞추기 위한 후보 검색이 아니라 기존 B1과의 원인 분리다.

| 영상 | 원래 XS 벡터각 / signed bias | B1 벡터각 / signed bias | C1 벡터각 / signed bias |
|---|---:|---:|---:|
| squat_0002 / cam1 | 3.80 / +1.06 | 12.68 / +12.33 | 12.38 / +11.85 |
| barbellrow_0003 / cam2 | 2.65 / −0.18 | 10.21 / +8.37 | 12.37 / +11.59 |

측면 몸통 방향 차이는 **C1에서만 새로 생긴 것은 아니다.** Fit3D로 미세조정한 B1에도 두 영상에서 확인된다. 이 결과만으로 학습 데이터·특정 손실항·골격 정의 중 하나를 원인으로 확정하지 않는다.

### 3. 다중시점 일관성은 운동·카메라 조합에 따라 달라진다

새 추론 없이 저장된 예측을 카메라 회전의 역변환으로 같은 world 좌표계에 옮겨, **동일 프레임**의 몸통 단위벡터 사이 각도를 계산했다. 라벨 몸통 방향을 점수에 넣지 않는 비교지만, 카메라 보정 자체가 독립 검증되지 않았다는 한계가 있다.

- 로우 정면(cam3)↔측면(cam1/2): 원래 XS 중앙값 18.18–31.38° → C1 11.35–13.39°. C1에서 개선되었다.
- 스쿼트 cam1↔cam2: 5.75° → 10.20°. C1에서 악화되었다.
- 모든 시퀀스·카메라쌍 표본을 합친 중앙값은 9.10° → 10.27°다. 로우 개선과 스쿼트 악화를 하나의 일반화 주장으로 합치지 않는다.

### 5. V 학습 입력의 관절 offset이 6–8°의 측면 감독 방향 차이를 만든다

C1 manifest의 실제 학습 NPZ를 읽어, 렙 안·몸통 4관절 각각 confidence≥0.3·측면각≤40°의 V 샘플에서 입력 2D와 3D GT의 XY 몸통 방향 차이를 집계했다. 중앙값은 squat 7.44°, barbell_row 8.33°였다. 실제 카메라 R 샘플에서는 squat 1.34–1.67°, row 3.45–3.47°다.

V 72시퀀스를 실제 저장 카메라로 재구성하여, 같은 프레임의 ① offset 없는 모캡 투영 ② fitted 관절 offset을 적용한 깨끗한 투영 ③ 실제 저장된 잡음 포함 입력을 분리했다. 아래는 **목표 − 입력의 수직 기준 XY 기울기 차이**를 단계별로 분해한 중앙값(°)이다. +는 목표 몸통이 입력보다 더 기울어졌다는 뜻이다.

| V 측면 운동 | 유효 표본 | 정상 원근투영 | fitted 관절 offset | 저장 입력 잔차 | 전체 |
|---|---:|---:|---:|---:|---:|
| squat | 2,638 | +0.007 | +6.37 | +0.20 | +6.68 |
| barbell_row | 1,280 | +0.051 | +7.22 | +0.95 | +8.33 |

단계별 중앙값은 합산할 수 없다. 프레임별로는 분해 항의 합이 전체 차이와 일치한다. 재생성 GT와 저장 GT의 방향 차이는 최대 0.000027°다. 원근투영의 **절대 방향 차이** 중앙값도 squat 0.11°, row 0.076°로 작다.

따라서 **이 V 측면 학습 방향차의 주 성분은 입력에만 적용하는 fitted 관절 offset**이다. 입력 COCO 계열 관절과 출력 모캡 관절의 정의 차이를 모델이 학습한다는 사실이며, 정의 변환 자체가 잘못됐다는 뜻은 아니다. 이 학습 차이가 Exercise3D의 C1 약 10° 편향을 야기했다는 인과관계는 아직 입증하지 못했다. V를 쓰지 않은 B1에도 현상이 있어 V 단독 원인으로 결론 내리지 않는다.

학습 손실은 `MPJPE + 0.5 × NMPJPE + 20 × velocity`이며 별도 XY 투영 손실은 없다. 이것만으로 손실 설계가 잘못됐다고 결론 내리거나 바꾸지 않는다.

## B. 가설

- 미세조정 목표 골격과 입력 2D/Exercise3D 라벨 골격의 정의 차이가 몸통 방향 변화에 관여할 수 있다. V 입력에서 정의 offset의 크기는 확인했지만, C1 예측의 Exercise3D 편향과의 인과관계는 아직 미확인이다.
- V의 원근·offset·잡음 성분은 분해했다. 학습 손실·시점 분포가 최종 모델에 미친 영향과 Sapiens2 라벨의 해부학적 차이는 분리하지 못했다. 새 학습이나 held-out 결과에 맞춘 보정은 하지 않았다.

## C. 이전 판단 수정

- Exercise3D 몸통의 “중력” 표기는 부정확했다. `up_c`는 여러 카메라 수직축 평균에서 만든 **추정 위축**이다. Fit3D의 알려진 실제 중력과 구별한다.
- “라벨이나 카메라 기울기 때문일 가능성”은 이전의 가설이다. 이번에는 카메라 위축만으로 설명할 수 없고, 모델 출력의 영상면 방향 변화가 존재함을 확인했다.
- 원래 XS가 측면 몸통 각에 가깝다는 사실을 전체 3D 정확도가 더 좋다는 뜻으로 쓰지 않는다. 같은 진단의 정면에서는 C1이 낫고, 기존 팔다리 결과도 C1이 개선했다.

## D. 데이터 신뢰도와 한계

- Exercise3D P2/P3의 3시퀀스만 사용했다. Sapiens2 삼각측량은 의사 정답이며 카메라 metadata에 `not_independent_camera_validation=true`가 기록되어 있다. 생체역학적 정확도를 확정할 수 없다.
- 표본 진단은 매 5프레임이다. 기존 사전 등록의 전체 프레임 렙 극값·합격 여부를 다시 정의하지 않는다.
- `xs_eval`의 문제가 나온 단계에 맞춰 **Pose3DConstraints 전 XS 출력**을 조사했다. 실제 폰 앱의 crop·Core ML·시간 추적·제약·경고 결과를 대체하지 않는다.
- Fit3D/Exercise3D 영상·이미지를 열거나 내보내지 않았다. 예측 배열·데이터는 Home에 있고 보고에는 집계만 남겼다.

## F. 권고

- C1 몸통 계열 규칙 보류를 유지한다. 미해결 오차를 threshold를 느슨하게 바꾸는 방식으로 감추지 않는다.
- 기존 C2와 2D·det·C3 사슬은 그대로 진행한다. 이 진단을 이유로 레시피를 바꾸거나 학습을 추가하지 않는다.
- 다음 원인 검증에는 **학습 피험자만으로 정한 관절 정의 변환을 입력·목표·평가에 일관되게 적용한 평가 또는 통제 실험**이 필요하다. 이번 held-out 결과에 맞춰 offset을 피팅하거나 acceptance 기준을 바꾸면 안 된다. 예정 C3가 이 문제를 자동 해결한다고 가정하지 않는다.
- 현재 39클립 폰 비교와 이번 원인 진단을 구분하여 함께 본다. 모델 채택은 팔다리 개선·측면 몸통 편향·정면 결과·실제 앱 경고를 모두 보고 판단해야 한다.
