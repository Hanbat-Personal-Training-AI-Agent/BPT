# BPT 운동팀 역할과 판정 계약

조사일: 2026-10-23. 대상: 일반 성인의 저항운동 기술 코칭. 이 문서는 **구현 전 명세**이며 앱의 현재 동작은 [차이 분석](gap_analysis.md)에 기록한다. 영상·데이터셋·모델 가중치는 열지 않았다.

목표 흐름은 카메라 → Halpe26 2D → 3D lifting → 규칙 → Kori 음성·말풍선, 세트 후에는 서버 GVHMR 검토다. 현재 실시간 평가기의 경고 판정은 2D이며, 3D 입력이 있더라도 일부 지표를 기록하는 수준이다. [현재 판정 코드](../../ios/Runner/NativePose/Evaluators/FormWarnings.swift), [GVHMR 논문][G]

프로필은 사용자의 목표·경험·수행 가능 범위에 맞춘다. ACSM의 2026 입장문은 건강한 성인의 점진적 저항운동과 개인화를 뒷받침하지만, 휴대폰 영상의 결함별 각도 임계값을 제시하는 자료는 아니다. 따라서 “PT 엄격”도 특정 변형의 기술 피드백 강도를 뜻하며 모든 사용자에게 같은 자세·ROM을 강제하지 않는다. [ACSM 2026][A]

## 근거와 심각도

| 표기 | 사용 원칙 | 근거 |
| --- | --- | --- |
| 연구 | 실험 조건·대상·좌표계를 함께 기록한다. 실험에서 비교한 각도를 부상 임계값으로 바꾸지 않는다. | [벤치프레스 역학 실험][B] |
| 기술 지침 | 협회·코치의 운동 수행 기준이다. 임상적으로 검증된 위험 경계와 구분한다. | [NSCA 기술 교육][N] |
| `P:` 제품 제안 | 임시 감지값·발화 정책이다. 인용 자료는 원칙의 근거이며 **제안 숫자를 검증한 자료가 아니다**. 구현 전 별도 검증한다. | [NSCA 지도 전략][C], [피드백 연구][F] |
| `U:` 미정 | 타당한 자동 판정값이 없다. 사람 확인·추가 센서가 필요하며 자동 경고를 보류한다. | [GVHMR의 단안 복원 문제][G] |
| 안전주의 | 통증·통제 상실·장비 충돌 또는 부하 관리상 우선 확인할 후보. 자세만으로 부상 발생이나 진단을 확정하지 않는다. | [NSCA 통증 없는 진행][P], [요추 굴곡 검토][L] |
| 효율 | 선택한 변형·목표 ROM·일관성과의 불일치. 위험하다는 뜻이 아니다. | [NSCA 지도 전략][C] |
| 셋업 | 장비·촬영·변형 확인이 선행되어야 하는 상태. 확인 전 관련 기술 판정을 보류한다. | [NSCA 기술 교육][N], [GVHMR][G] |

## 역할

역할은 실행 주체의 책임 구분이다. 아래 운영 절차와 출력 형식은 모두 제품 제안이며, 외부 문헌이 특정 에이전트 구조를 검증했다는 의미는 아니다.

| 역할 | 책임 | 입력 | 출력 | 결정 규칙·근거 |
| --- | --- | --- | --- | --- |
| 헤드 트레이너 | 기준·변형·엄격도 승인, 충돌 중재 | 운동 목적, 사용자 선택 변형·모드, 통증 응답, 관찰 가능성, 다른 역할의 제안 | 버전 있는 운동 프로필, 우선순위, 허용 ROM, 보류 사유 | 통증·명백한 통제 상실을 최우선으로 처리한다. 다음은 안전 관련 셋업, 안전주의 후보, 효율 순서다. 불확실한 후보는 단정하지 않는다. [P], [L], [C] |
| 근력·컨디셔닝 코치 | 운동별 셋업·단계·교정 과제 정의 | 선택한 리프트·장비, 경험, 가동범위, 세트 결과 | 단계별 체크포인트, 결함 ID, 짧은 한국어 큐, 다음 세트 과제 | 변형을 먼저 확정한다. 일관된 Yates·랜드마인 로우에 Pendlay의 각도를 강제하지 않는다. [N], [R], [Y] |
| 운동역학 분석가 | 결함을 측정 가능한 신호로 번역 | 2D/3D 관절, 시간, 좌표계, 신뢰도, 장비·손 관측 여부 | 지표·단위·부호, 근거 수준, 불확실성, `measurable_now`, 필요한 감지 | 몸통선은 요추 곡률이 아니며 손목점은 손바닥 방향이 아니다. 측정하지 않은 힘·근활성·통증은 출력하지 않는다. [G], [B], [L], [관절 정의](../../ios/Runner/NativePose/PosePipeline/SimCCDecoder.swift) |
| 실시간 분석 에이전트 | 기기 내 결정적 규칙으로 세트 중 코칭 | 승인된 프로필·카탈로그, 유효 2D 및 검증된 경우의 3D, 단계·반복, 최근 발화 | 한 개의 `fault_id`·`cue_ko`, 표시/발화 시점, 보류·추적 안내 | 새 규칙을 즉석 생성하지 않는다. 감지와 전달을 분리하고 한 번에 한 큐만 말한다. 발화 정책은 아래 표를 따른다. [C], [F] |
| 심층분석 에이전트 | 세트 후 서버에서 GVHMR과 실시간 기록 비교 | 세트 시간 정보, 허용된 서버 분석 입력, GVHMR 관절·좌표계, 2D 관측·결측, 프로필·발화 기록 | 반복별 근거, 관찰 불가 항목, 잘한 점, 우선 교정 1개와 다음 세트 확인법 | 3D를 정답으로 취급하지 않는다. 2D 재투영·중력·접지·시간 일관성을 확인한 뒤 사용하고, 두 경로가 충돌하면 불확실성을 보고한다. [G] |

## 엄격도와 공통 결정 순서

| 모드 | 기술 기준 | 발화 제안 | 근거 |
| --- | --- | --- | --- |
| PT 엄격 | 선택한 변형의 기술 목표를 좁게 적용. 절대 셋업 기준과 개인 기준을 함께 확인 | 효율 문제도 유효한 1반복 확인 후 전달. 같은 키는 이후 2반복 및 8초 동안 억제 | `P:` [C], [F] |
| 표준 | 개인 기준 대비 의미 있는 변화에 집중 | 효율 문제 2반복 연속 확인. 같은 키는 이후 3반복 및 8초 동안 억제 | `P:` [C], [F] |
| 여유 | 통증 없는 개인 목표 ROM과 수행 지속에 집중 | 효율 문제 3반복 연속 확인. 같은 키는 이후 4반복 및 12초 동안 억제 | `P:` [C], [F] |

두 쿨다운 조건이 모두 해제되어야 다시 말한다. 위 초·반복 수는 최적값으로 입증되지 않았다. 피드백 연구에는 잦은 시각 피드백의 이점도 있으므로 “덜 말할수록 학습이 좋다”로 설명하지 않는다. 음성 빈도는 사용성 검증 대상이다. [F]

1. **변형·장비 확인:** 미확정이면 셋업 안내만 제공한다. 방향·그립을 몸통 각도로 대신 판정하지 않는다. [R], [Y]
2. **안전 입력 우선:** 사용자 통증 신고나 확인된 장비 이탈·통제 상실은 모든 모드에서 세트 중단 안내로 처리한다. 큐: “아프면 지금 멈춰!”. 안전 항목의 기준은 모드별로 완화하지 않는다. 이는 통증 없는 진행 원칙을 적용한 제품 정책이다. [P], [N]
3. **관측 품질 확인:** 필요한 관절·방향·단계가 없으면 `unknown`이다. 결측을 정상·개선·0도로 대체하지 않는다. 실시간 2D는 해당 운동면이 보일 때만 사용하며 폰 기울기와 가림을 확인한다. [G], [현행 시점 게이트](../../ios/Runner/NativePose/Evaluators/FormWarnings.swift)
4. **기준 설정:** `B`는 코치 또는 사용자와 확인한 통증 없는 목표 동작의 기준이다. 첫 3반복 중앙값은 변화 감지용 초기값일 뿐 정상의 증거가 아니다. 변형·카메라·부하가 바뀌면 기준을 재확인한다. [C], [P]
5. **지속성 확인:** `P:` 프레임형 후보는 유효 관측에서 0.2초 유지 후 후보화한다. ROM·반복 지표는 완결된 단계에서 판정한다. 안전주의 후보도 품질 검증 없이 즉시 확정하지 않는다. [C], [G]
6. **한 큐 선택:** 안전 관련 항목 → 효율, 같은 등급은 신뢰도 → 지속성 → 고정 ID 순으로 선택한다. 효율 큐는 반복 전환점/직후에, 명백한 중단 안내는 즉시 전달한다. 무거운 중량을 들고 있는 중에 몸 방향이나 그립 변경을 요구하지 않는다. [N], [C]
7. **발화·말풍선 일치:** 2–6어절의 친근한 반말 명령형을 사용한다. 큐는 관찰한 한 가지 행동만 바꾸며, “잘못됐어” 같은 평가만 전달하지 않는다. 발화 중 다른 큐는 겹치지 않는다. 형식·중재 규칙은 `P:`다. [C], [R]
8. **칭찬:** `P:` 지적했던 지표가 2회 연속 유효하게 개선되고 더 높은 우선순위 문제가 없을 때 구체적으로 칭찬한다. “지금 몸통 안정적이야!”처럼 관찰 범위를 한정한다. 경고 없음·추적 실패·기능 비활성만으로 “완벽해”를 말하지 않는다. [C], [G]

## 측정 계약

다음은 앱에 필요한 **계산 정의**다. 기하량을 정의하는 것과 그 수치가 안전·위험을 가르는지는 별개다. 단안 복원의 좌표계·가림 문제와 역학 연구의 측정 조건을 반영했다. [G], [B]

| 기호 | 정의·단위 | 제한 |
| --- | --- | --- |
| `S,H,E,W,K,A` | 같은 쪽 어깨·고관절·팔꿈치·손목·무릎·발목; 중심점 사용 여부를 지표별 명시 | 좌우를 프레임마다 섞으면 변동을 만들 수 있음 |
| `L` | 해당 프레임의 어깨–고관절 길이 | 짧게 투영되면 정규화 불안정; 2D/3D 길이를 혼합하지 않음 |
| `theta` | 몸통 `H→S`와 위쪽 수직의 부호 있는 각도. 앞 기울임 양수, 뒤 젖힘 음수, 선 자세 0° | 현재 2D 영상 수직은 실제 중력과 다를 수 있음 |
| `alpha` | 앞쪽 힌지 구간에서 지면과 몸통의 각도 `90°−theta`; 수평 0°, 수직 90° | “45°”는 기준축을 함께 표기 |
| `e,k,h` | `angle(S,E,W)`, `angle(H,K,A)`, `angle(S,H,K)` 내각, 편 자세 약 180° | 임상 굴곡각은 `180°−내각`; 예: 무릎 굴곡 30°는 `k=150°` |
| `d_hip` | H에서 S–A 선까지 부호 있는 수직거리 / S–A 길이; 바닥 쪽 양수 | 요추 굴곡·복압이 아닌 몸통 정렬 대리량 |
| `d_head` | 귀에서 H–S 선까지 부호 있는 수직거리 / L; 바닥 쪽 양수 | 경추 분절각이 아님 |
| `p_elbow` | E의 H–S 선 뒤쪽 수직거리 / L; 등 쪽 양수 | 견갑 후인·실제 바 도착점을 증명하지 못함 |
| `ROM_loss` | 승인 기준의 가동범위 또는 끝점과 현재 반복의 차이 | 계획한 부분 반복과 가림 제외 |
| `d_bar` | 검출한 바 중심과 정강이/목표 몸통 영역의 거리 / L | 손목 좌표로 바 검출을 대체하지 않음 |
| 시간·분위수 | 초 단위 timestamp, 유효 샘플의 중앙값·P05·P95 사용 | 제안의 P95−P05 범위는 현행 max−min과 다름; 프레임 수를 초로 오인하지 않음 |

`measurable_now`는 **현재 센서 입력으로 해당 신호를 얻을 수 있는가**이며 경고 활성화 여부가 아니다. `yes`=조건을 갖춘 시점에서 직접 계산 가능, `partial`=대리량·제한된 시점만 가능, `no`=현재 신체점만으로 부족. 각 CSV 행의 `needs`가 추가 조건을 명시한다. Halpe26의 발점은 이용할 수 있지만 손가락·손바닥·바·고정점·벤치·척추 분절·견갑 랜드마크는 현재 평가기 입력에 없다. [관절 정의](../../ios/Runner/NativePose/PosePipeline/SimCCDecoder.swift), [G]

3D로 개선할 수 있는 것은 관절각의 투영 오차·좌우 비교·시간 일관성이다. GVHMR의 인체 메시만으로 손의 회내/회외, 척추의 실제 곡률, 견갑 움직임, 바 경로, 관절 토크, 통증을 측정했다고 주장하지 않는다. 모델이 추정한 자세와 별도로 관측한 장비·손 증거를 구분한다. [G], [B], [L]

## 공통 출력과 세트 후 보고서

`P:` 이벤트는 `exercise`, `variant`, `rule_version`, `mode`, `fault_id`, `phase`, `rep_index`, `time_range_s`, `metric/value/unit`, `coordinate_frame`, `quality`, `decision(observed/unknown/not_applicable)`, `severity`, `cue_ko`, `sources`를 보존한다. 감지 결과와 실제 발화 결과를 따로 기록한다. 이는 출처와 측정 조건을 보존하기 위한 제품 계약이다. [G], [B], [C]

`P:` 심층 보고서는 다음 순서로 출력한다. [G], [C], [P]

1. 운동·변형·세트 범위·평가 가능한 비율, 2D/GVHMR 품질과 관찰 불가 항목.
2. 확인된 잘한 점 한 가지와 최우선 교정 한 가지. 통증 응답이 있으면 먼저 처리.
3. 반복·시간별 지표, 기준, 초과량, 근거 URL. 바·그립은 실제 관측이 있을 때만 기술.
4. 실시간 경고와 일치/불일치, 불일치 원인 후보. 증거 부족은 보류.
5. 다음 세트 행동 1개, 확인할 지표 1개. 필요 시 부하·ROM을 낮춰 다시 확인하되 자동 중량 처방은 하지 않음.

보고 예시(가상값): “랜드마인 방향은 고정점이 보이지 않아 판단 보류. 5–6회에서 몸통 변동이 기준보다 커졌어. 다음 세트는 ‘몸통 각도 유지해!’에 집중하고 같은 시점에서 변동을 다시 확인하자.” 이 예시는 실제 영상 분석 결과가 아니다. [R], [G]
