# 스쿼트

조사일: 2026-10-23. 맨몸·고블릿·하이바·로우바를 구분한다. 각도·심각도·`P:`/`U:`는 [공통 계약](team.md), 모드별 조건은 [CSV](fault_catalog.csv)를 따른다.

로우바·넓은 스탠스는 하이바·좁은 스탠스와 관절 모멘트 분담이 다르다. 모든 사람에게 같은 절대 몸통각이나 발 너비를 강제하지 않는다. [S2], [S5]

## 문헌 수치와 적용 한계

- Fry 등(2003)은 훈련된 남성 7명에서 무릎 전진을 막을 때 무릎 모멘트가 줄고 고관절 모멘트가 크게 증가함을 보고했다. **“무릎이 발끝을 넘으면 오류” 규칙은 만들지 않는다.** 이 실험의 N·m 값을 영상 감지 임계값으로 쓰지 않는다. [S8]
- Lorenzetti 등(2018)의 발끝 0°·21°·42°는 비교 조건이다. 개인에게 21°를 정답으로 주거나 무릎/발목 간격비 1.0을 위험 경계로 해석하지 않는다. [S2]
- 깊은 스쿼트를 일괄 위험으로 분류하지 않는다. 깊이·하중·기술·개인 가동범위를 함께 본다. 허벅지 수평은 기술 목표가 될 수 있지만 고관절 키포인트 높이는 실제 고관절 접힘선과 다르다. [S4], [S6]
- `P:` 깊이 부족의 기준 대비 내각 증가 >10°/15°/20°(엄격/표준/여유), 힙 선행의 몸통 변화 >8°는 검증 전 후보다. 후자는 세 모드에 동일하게 적용하고 속도 동시 조건을 요구한다. 문헌에서 검증된 부상 컷오프는 확인하지 못했다. [S3], [S5]

Halpe26 발점은 뒤꿈치 들림·발 방향 확인을 보완한다. 측면만으로 정면 무릎 정렬을 평가하지 않으며, 바 경로·랙 이탈은 물체 검출이 필요하다. 3D lifting은 몸통과 다리의 자세를 보완해도 요추 곡률·지면반력은 직접 제공하지 않는다. [S6], [S9]
